# 击键测速 — 条件击键当量建模

**条件击键当量**（Conditional Keystroke Equivalent，简称"当量"）：从个人打字测速数据中学习**前后键条件下**键位间的击键时间成本（ms，非物理距离），输出按键时间母表与 2/3/4 键总当量表（错误成本内含），用于输入法编码方案评估与键位优化。

**摘要**：传统键位成本模型用 2 键当量逐对累加，假设"打完一个键手就回位"。实测表明该假设系统性低估整串耗时，且低估幅度按键对类型不均（跨手 +31ms → 同手异指 +85ms，§5.4）——用其评估编码方案约 17.1% 的排序会被扭曲。本项目以"对称条件段"为单位建模：每段时间 `S(p,a,b,n)` 同时以前两键与**后继键**为条件，总当量 = 段当量之和；错误成本按段类计入，段当量 = 按键时间 + 错误成本（§4.6-§4.7）。固定 trial 测试集上总时间 MAE 36.5ms（R² +0.661）、排名精度 Spearman 0.814，4 码/2 键两项分别领先陈一凡 1986 群体两键表 34%/52%（§5.3）；模型已贴实测噪声量级（§5.2）。

## 1. 引言

键盘输入的时间成本模型是输入法编码方案评估与键位优化的基础。传统工具（Carpalx、KLA 类）以 **2 键当量表** B(a,b)——键对 (a,b) 的击键时间——逐对累加估算整串耗时：

```
T'(abcd) = B(a,b) + B(b,c) + B(c,d)
```

其隐含假设：键对间独立，打完一个键后手回静止起始位。该假设在两个层面失实：

1. **串中键对的前键从不是"空"**：打完 `r` 后手指停在 `r` 位，击打 `w` 的起点不是 home 位——相邻间隔互为条件、上一键准备完成后可直接启动下一键（Rumelhart & Norman 1982 的"间隔负相关"与"不回位"）。
2. **低估幅度按键对类型不均**：有前键的中段比空前键首段慢（跨手 +31ms、同手异指 +85ms，§5.4）——统一比例修正处理不了"同手段被低估更多"的结构性错位，编码方案排序被扭曲（约 17% 排序不一致）。

本项目以**对称条件段**为单位直接建模：段 `S(p,a,b,n)` = "前两键为 p,a 时击打键对 (a,b) 的按键时间（含后继键 n 的准备成本）"，总当量 = 段当量之和：

```
T(abcd) = S(∅,a,b,c) + S(a,b,c,d) + S(b,c,d,∅)
```

2 键表是段模型在空前键（∅）+ 无后继（∅）下的特例切片——2/3/4 键当量同源同尺度，完全自洽。

主要结果与贡献：

- **对称条件段模型**：前键条件效应 +31~+85ms 且按键对类型不均（§5.4）、后键条件化（φsuc7，v2 落地设计）——单一段表示统一 2/3/4 键当量
- **个人稳定期数据全链路**：2/4 键混采协议（欠样本加权、随机延迟去节律）、稳定期边界方法（自动剔练习漂移，§5.1）、B4b 两阶段残差异常剔除（§4.5）
- **部署混合模型 v4**（XGB + 神经分量 ×5 固定种子平均，无选优噪声；段角色 φ19）：固定 trial 测试集 T₄ 总时间 MAE 36.1ms / R² +0.683 / 4 码排名 Spearman 0.811，T₃ 留出 30.4ms（§5.2），4 码/2 码两项分别领先陈一凡 1986 群体两键表 34%/55%（§5.3）
- **段类条件错误率模型与段当量**：错误成本（错误率 × 实测错误修正时间，随采集动态更新）按段类计入，"当量"完整定义 = 按键时间 + 错误成本（§4.6-§4.7）
- **样本量终局**：模型已贴实测噪声量级（段组内 σ≈33.3ms，§5.2），专项扩容零收益

## 3. 数据

### 3.1 采集协议

`python 采集-按键时间和错误率.py`（tkinter GUI）：显示随机编码，录入真实击键时间戳。

**2/4 键混采**：每试次以 P2=0.30 概率出 **2 键码**（其余 4 键）。2 键试次服务对称段模型的 T₂ 角点 S(∅,a,b,∅) 测量——4 键试次的首段总带真后键，该"词首+词末"组合只能靠 2 键试次直接测量。2 键与 4 键各用**独立的欠样本键对池**：4 键池喂段覆盖，2 键池喂 900 键对的角点覆盖；2 键行 code 长度 2、c_d/d_d=0 填充，下游按 `len(code)==4` 过滤。

| 操作 | 行为 |
|------|------|
| 输入显示的 2/4 个字符 | 正常打字 |
| 输错（任意键） | 立即变红停止，进入随机延迟 |
| 空格 | 跳过当前组（不记录），进入随机延迟 |
| Esc | 退出 |

**采样策略（多样性加权）**：首键均匀随机，后续键按 `w(b|a) ∝ 1/(n(a,b)+1)` 加权——欠样本键对优先（符号键 `;,./` 零样本时自动补足），键对样本量趋均衡后自动回归均匀随机。每次试次结束（正确/错误/跳过统一）延迟 **300-800ms 随机**再显示下一组，打断固定节律，防止"预期性击键"把键对难度差异压缩平均。

## 4. 方法

### 4.1 问题定义

给定 4 字符编码 `abcd`，预测击键总时间 T（ms）。训练数据每行记录一个随机 4 字符串的实际击键时间戳。

### 4.2 对称条件段模型（v4 混合部署 · 段角色感知）

将序列拆成**段**（n 键码 → n−1 段），每段独立预测，条件 = **段角色 + 前两键 + 后继键**：

```
每段 t = 双线性交互(e) + MLP(e, φ19)   S(角色,p,a,b,n) ≈ e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b
                                                     + MLP(79→128→64→1 + Dropout0.2)
  前键空/无后继 = 索引 30（∅）
  φ19 = φ8(a,b) 几何 + φsuc7 后键 [存在, 同手(b,n), 同指(b,n), 同键(b,n), Fitts(b,n), 同手(a,n), Fitts(a,n)]
        + 段位块 4 维 [i==2, i==3, L==3, L==4]   (i=段位, L=码长; 2026-09-21 落地, 6 角色两两可分辨)

段角色 (码长 L, 段位 i) — 等价的 6 类:
  L2i1 角点 S(∅,x,y,∅) · L3i1 / L4i1 首段 S(∅,x,y,z) · L3i2 短尾 S(x,y,z,∅)
  L4i2 中段 S(w,x,y,z)   · L4i3 长尾 S(x,y,z,∅)
  为什么必需: (p,a,b,n) 只编码「是否首段/是否末段」——3 键 seg2 与 4 键 seg3 签名相同
  ((有前键,无后键)) 却是不同角色, 单表无法表达 (与错误侧 09-19 段类重参数化同因)

部署混合 (BlendModel): S̄ = 0.3×XGBRegressor(独热124+φ19) + 0.7×mean_{s∈{0..4}} S_deep2(s)
  无选优环节 → 无选优抽签噪声 (决策带从 ±3 缩至仅测试重洗 ~±1ms), 同数据逐位确定

整串当量统一公式 (n 键序列 k₁k₂...kₙ; 首段前键=∅, 末段后键=∅):
  两键  T₂(xy)   = R(L2i1)[x,y]                                       ← 1 段 (角点, 2 键试次实测内插)
  三键  T₃(xyz)  = R(L3i1)[x,y,z] + R(L3i2)[x,y,z]                    ← 2 段
  四键  T₄(wxyz) = R(L4i1)[w,x,y] + R(L4i2)[w,x,y,z] + R(L4i3)[x,y,z] ← 3 段
```

### 4.3 模型结构

输入四元组 `(p, a, b, n)` 中三键 `(p,a,b)` 经**共享嵌入**与**交互部分**两条路径汇合后加 MLP 头，后键 `n` 经 φsuc7 特征进入 MLP（sym_phi 形式）。部署为混合（XGB 分量 + 神经分量×5 平均）。

```
输入: ids = [p, a, b, n]（31 索引, n 仅经 φ 生效）, φ19 = φ8(a,b) + φsuc7(b/a, n) + 段位块 4 维
共享: e_p, e_a, e_b = E_key[ids[:, :3]]   E_key ∈ ℝ³¹ˣ²⁰（30 键 + ∅）
```

**① 神经分量（deep2 v4，20,509 参数）**——两两配对交互 + 深化 MLP：

```
S(角色,p,a,b,n) = e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b  +  MLP([e_p; e_a; e_b; φ19])
```

| 组件 | 形状 | 说明 |
|------|------|------|
| W₁/W₂/W₃ | 3 × (20×20) | 显式二阶交互：前键×首键、首键×次键、前键×次键 |
| E_key | 31×20 | 通用键位嵌入（与 W 共享同一套嵌入） |
| MLP | 79→128→64→1 (ReLU+RMSNorm+Dropout0.2) | 非线性残差（含 φsuc 后键 + 段位块）；dropout 使集成成员去相关、放大预测平均收益 |

**② XGB 分量（确定性）**——XGBRegressor（500 树 / lr 0.06 / depth 6 / subsample 0.8 / colsample 0.8），设计矩阵 = 独热(p,a,b,n 各 31) 124 维 + φ19 = 143 维；种子稳定 ±0.18ms；自适应部分模式匹配（叶子 = 部分键模式 + φ 区间），对零样本组合外推同样有效（见过/未见三元组分组验证优势均匀）。

**③ 混合**：S̄ = 0.3×S_xgb + 0.7×mean(S_deep2, seeds 0-4)。

**模型选型依据（09-14 当前数据全家族重跑，`实验/实验-架构对比{,2,3}.py`，原始 test 口径、神经 5 配对种子）**：全局最优 = 本混合 41.6ms / R²+0.592（对 ens5 −0.6、对单模最优 XGB −1.1、对神经单模 −2.4）。各类最优——**树系** XGB 42.7（单模最优，HistGBM 43.9 / RF 45.5 / ET 51.7）；**神经系** base 44.0（容量维 de32/dh128/再加深均持平 Δ≤0.2；结构删件全显著：no_w3 +2.6 / mlp_only +2.1 / bi_only +3.6 / 删φ +1.7）；**组合系** ens5 42.2。维持废弃：FT-Transformer 48.7（慢 ~12×）/ ResMLP 47.1 / 全局 FM 47.0 / 高斯秩目标 51.6 / 注意力聚合 47.4 / CP 张量分解 48.7 / 核方法 48.1 / kNN 70+ / ridge 49.0；目标函数 l1 / huber50 与 mse 已无差（±0.2）。

### 4.4 键位嵌入与几何特征

键盘为 **3 行 10 列完整 QWERTY（30 键）**：26 字母 + `; , . /`。每键独立可学习向量 `e_k = E[k]`。当量定义：**期望键对耗时，单位 ms**（模型预测原始值，不做相对归一化）。

键位嵌入本身不含手指归属信息，显式注入 8 个文献特征：

```
φ(a,b) = [same_hand, same_finger, same_key, col_dist, row_dist, fitts,
          mirror_pair, cross_row_same_finger]

same_hand(a,b)  = 1  如果 a 和 b 在同一只手（左手=col 0-4，右手=col 5-9），否则 0
same_finger(a,b)= 1  如果 a 和 b 用同一根手指按下，否则 0
same_key(a,b)   = 1  a==b 同键重复（零幅移动需单独建模, 不适用 Fitts）
col_dist / row_dist  = |列差| / |行差|（İşeri & Ekşioğlu 2015: 列>行>手 重要性）
fitts(a,b)      = log2(1 + √(col² + (2·row)²))   Fitts 对数项, W=键宽, 行距≈2 键宽
mirror_pair(a,b)= 1  异手对称手指（Grudin 1983: 换位错误集中于镜像手指）
cross_row_same_finger(a,b) = 1  同指跨行（keygen: 同指顶↔底行最慢最易错）
```

**消融结论**：逐特征 leave-one-out 全部持平（特征互为冗余），但整体删除损失 +1.7ms、角点 +3.2ms（09-14 当前数据复测，与 08-14 原测同值）——φ 作为整体提供嵌入补不上的几何先验，价值在稀疏三元组外推（2/3 按键时间表条目零样本）。手工指对类别编码（独热）与键嵌入+双线性等价（嵌入本身即更细的键对类别表示）；生理学导向改造（指距替代列距等）经两轮独立批实验全部关闭，φ8 维持。

### 4.5 训练协议

- **目标**：批量 MSE（段级），验证集 20%，早停 patience=60，Adam lr=0.001
- **训练形态（无选优）**：固定种子 0-4 训练 5 个神经分量取**预测平均**，与确定性 XGB 混合部署——同数据逐位可复现。选优环节（best-of-N）曾引入 ±2ms 抽签噪声（验证最优候选可为测试最差），已移除
- **可复现性与并行**：模块导入即固定运行环境（单线程+播种）；训练成员构造显式种子化 → 每成员 = (seed, 数据) 纯函数，全流程 25 次训练经 spawn Pool 并行（多核 `--full` 约 4 分钟），`KJ_SEQ=1` 强制串行；并行/串行产物逐位一致
- **验证集泄漏**：同一 trial 的三段共享个人速度因子（trial ICC 0.308），段级随机划分使验证集系统性乐观 ~9ms——**模型对比与报告口径必须用 trial 级留出**（§5.1）
- **异常剔除（B4b 两阶段残差，键对分桶）**：
  1. 段位置分桶 MAD k=3 剔除 → 训练 M0（干净模型提供"期望行为"）
  2. M0 推全数据 → 带符号残差 `y−ŷ`（正 = 比预期慢）
  3. 残差按**键对 (a,b) 分桶**、**单侧上围栏**（r ≥ med + 3·1.4826·MAD）剔除——只删"比该键对合理预期慢"的段（注意力中断只拖慢不加快；偏快是 rollover/预备连击的真实行为不删）。剔除率随池变化（当前稳定期池实测 ~2.7%，早期快照 ~4.8%；van Selst & Jolicoeur 1994 调研范围 5-10% 内）
  - 依据：全局残差法会把"模型学不会的难键对"的真实慢段当异常删（用模型偏见定义正常，循环论证）；键对分桶修复当量失真。剔除收益在**当量稳健性**而非预测精度（无剔除与 B4b 的测试 MAE 在噪声内）
- 段样本：每 trial 3 段（t₁: 空→ab, t₂: a→bc, t₃: b→cd），共享 MLP 头，段间互相增强

### 4.6 键对错误率模型与错误修正时间实测

一次按键错误的代价与键对运动难度解耦——错误成本（错误率 × 错误修正时间）按段自身键对、按段类条件计入（实证 §5.5）。两个数据源：

**① 错误率 P_err（`分析-错误率.py`，全量数据）**：

```
P_err(a,b | 段类) = σ(w·feat(a,b) + β·有后键 + δ·(段位−1))          ← 纯加法（2026-09-21 去交互项）
段类 = (有前键, 有后键, 段位)，共 5 类（由 码长×段位 映射；2026-09-19 重参数化）
五类电平（相对 c0）: c1=+β, c2=+δ, c3=+β+δ, c4=+2δ
当前拟合（41298 键对事件 / 783 错误，1.90%）:  β=+0.450 ± 0.125 (z=+3.60)   δ=+0.875 ± 0.083 (z=+10.5)
类均值: c0 角点 0.57% / c1 首段 0.89% / c2 短尾 1.36% / c3 中段 2.11% / c4 长尾 3.18%
类校准 O/E（观察/期望）: c0 0.72 / c1 1.03 / c2 1.20 / c3 0.99 / c4 1.00（c0/c2 偏离在 Poisson 噪声内）
```

**交互项 γ 已删（2026-09-21 用户决策）**：γ(有后键×段位) 在段类重参数化后的口径下历次都不显著（−0.10±0.17, z=−0.58），而**判定它需 ~1276 场数据**（§5.7）、点估计 ≈0 意味其对总当量影响在第四位——删掉换 2 个自由度。收益立刻兑现：**β 的 SE 从 0.270 降到 0.125（z 由 2.1 升到 3.6）**，因为 γ 与 β 共线，去掉约束后那份信息回到 β（LRT 监控 D=0.344, df=1, p=0.56 → 加法形式不被数据拒绝）。**`分析-错误率.py` 每次运行都会并排拟合一次带 γ 的版本并报 D/p**，作为"删得对不对"的常设监控。段当量随之变化 ≤0.6ms/段（T₂ +0.5 / T₃ +0.3 / T₄ −0.2ms）。
```

**为什么不再用四类签名**：旧签名 (有无前键, 有无后键) 在**仅 2/4 键数据**上与 (码长, 段位) 一一对应——是无损重参数化，当时既不会错也看不出来；加入 3 键后「尾段」类被劈为 c2（3 键段 2，实测 1.64%）与 c4（4 键段 3，实测 3.15%，z=−3.08, p=0.0020），旧模型显著拟合不足，新五类模型 D=0.14（p=0.71，09-19 复核）/ 09-21 复核旧四类 D=8.87（p=0.012）、五类 D=1.31（p=0.52）。同时**「有前键」不再单列**：观测数据里 有前键 ⟺ 段位≥2 完全共线，旧模型的 α=+2.10 实为位置效应，引入段位项后塌缩为 0（z=0.02）。段类的物理含义：**起始保护**（c0 角点 0.57% ≪ c1 首段 0.89%）、**末位保护**（同段位下无后键更低，β>0）、**码内累积负担**（无后键三格随段位 0.41→1.64→3.15%，δ）。

特征为键位可计算量（同手/同指/坏指对类/目标行等，9 vs 13 特征集按 5-fold AUC 自动选型）；原始键对统计噪声大（平均 ~46 事件/键对）故用特征结构约束，键对级残差不可辨识。**选型随数据在两组间摆动**（09-14 版 AUC 0.642/0.644 → 13 特征入选；09-21 版 0.648/0.647 → 9 特征入选）——两集差值 ≤0.001 在折间噪声内，等于告知"文献扩充 4 特征（镜像手指/跨行同指/相邻手指/b靠拇指）在大样本下已被 9 特征基线吸收"，**不要在单次快照上读入选结果**。**事件口径**：2/3/4 键行全入模；错误 trial 在错键截断——错键对只记 err、其前的键对记 ok、首键即错不记事件（键对未尝试）。

**② 错误修正时间 cost（`采集-错误修正时间.py` + `分析-错误修正时间.py`）**：连续长随机串（120-200 字母）+ 自然回退纠错，单框逐字符着色（白=未打/绿=对/红=错）——错误发现以立即型为主，对应短码语境。测量"**首错按下 → 首错位置打对**"的净耗时（反事实世界尾段同节奏平移，原始区间即净成本）；连锁错（含同位二次错）吸收为单事件——错误只计首错、时长只记首错间隔；episode 判定在采集端实时完成，只落盘错误键事件与串汇总（`数据/错误修正时间-错误键.tsv`）。

**时长异常剔除（分析端）**：过程分桶（发现型 imm × 退格数档）桶内单侧 med+3×1.4826×MAD 围栏——语义同 S 模型剔除（注意力中断只拖慢不加快，只删过大侧）；退格/盲打是时长的过程簿记结构（+~400ms/退格、+~350ms/盲打字母）**必须分桶**，否则误删合法的连锁/盲打长纠正；桶 n<8 不设栏（保守）；剔除只作用于时长统计，事件计数与率仍用全部闭合 episode。

**当前实测**（282 事件 / 22959 按键 / 12 有效坐姿，弃首坐姿+围栏剔 4 后 n=278）：全体 782ms（SE 15）/ 立即发现 701ms（n=212）/ 延迟发现 1042ms（n=66）。双成分结构：延迟 = 立即 + 过程增量（回归截距与立即均值差 +4ms 定量成立）。

**定案机制**：续采监控，三判据全满足即冻结 cost——①簇稳健 SE≤30ms（均值位置钉住，T₄ 传导 <±2ms）②近 10 坐姿斜率不显著（近端窗口）③近 5 坐姿均值与全体差 <40ms；监控规则：单次刷新均值变动 >±75ms（2×簇SE）回查。cost 为乘法标量，对优化排名零影响、只定绝对刻度。导出 `产物/错误修正时间-实测值.txt`（label 行式：cost_ms 数据行 + 手别诊断行——左/右手目标纠错差 +69ms（t=4.1，同手纠错串惩罚，退格位依赖的布局结构），为当量表通用性不入表）。

### 4.7 段当量与产物链

错误率模型与按键时间模型合并，构成本项目标准产物链（`组装当量表.py`）：

```
段当量 = 按键时间 S(段角色,…) + 错误率 P_err(a,b|段类) × 错误修正时间 cost  → 段当量表.npz（按段角色 6 个切片, version 5）
  cost = 错误修正时间实测标量 (产物/错误修正时间-实测值.txt, 分析-错误修正时间.py 导出, 随采集动态更新)
段角色 (码长,段位) 6 类 → 错误侧段类: L2i1→c0 · L3i1/L4i1→c1 · L3i2→c2 · L4i2→c3 · L4i3→c4
总当量（2/3/4 键当量）= 段当量求和:                                            → 总当量-2-4键.txt
  T₂(xy)   = seg_L2i1(xy)
  T₃(xyz)  = seg_L3i1(xyz) + seg_L3i2(xyz)
  T₄(wxyz) = seg_L4i1(wxy) + seg_L4i2(wxyz) + seg_L4i3(xyz)
```

切片结构两次演进都源于同一件事——**同签名跨码长的角色分裂**：2026-09-19 错误侧先按段类（= 签名 × 段位）拆成 5 片（(有前键,无后键) 格因码长不同分裂为 c2 短尾 / c4 长尾）；2026-09-21 时间侧也落地段角色（φ19），而时间侧连 c1 也要拆（L3i1 与 L4i1 按键时间不同、错误率仍同属 c1），故段当量表改为按**段角色** 6 片。

即**本项目"当量"的完整定义包含错误期望成本**（按键时间表与错误率表作为两个源表一并保留）。

### 4.8 设计边界

- ❌ **字母 N-gram 频率**：不引入自然语言熟悉度偏差，纯随机采样
- ❌ **连组模式**：每组独立开始（模拟分词间自然停顿），不建模组间转移
- ❌ **节奏/节拍器**：随机延迟打断节律，按"打对条件下尽可能快"测试
- ❌ **变长编码**：仅测 2/4 字符编码（3 键当量为按键时间表切片组合）
- 🎯 **应用域 = 4 码内**：当量的优化与使用仅限 4 码内词内评估（主要 4 码二字词，词间自然分词间隔）——孤立 4 键试次的范式与真实词内输入结构一致；跨词连续序列不在建模范围

## 5. 结果

### 5.1 评估口径

**统一口径：稳定期内固定 trial 测试集**。`stable_pools`（分析-按键时间.py）边界方法（序号块口径）：正确 4 键 trial 按时间序切等大块（150 trial/块）→ 每块总时中位 → 3-块滚动中位平滑 → R = 末 5 块平滑值中位 → 自末向前最早连续满足 平滑值 ≤ R×1.10 的块起（确定性无随机）；2 键 trial 不参与边界计算，按时间序自稳定起点同截归属。稳定期内 seed 2024、20% trial 留出，训练/评估只作用于训练侧，测试集独立 B4b（内部自训 M0，与训练无信息交换）。`python 分析-按键时间.py` 直接输出（确定性流，重跑必得同值）。**部署模型同用稳定期全量**（当量表 = 当前状态语义）。**例外：错误率模型（分析-错误率.py）仍用全部数据**（用户决策不随练习过滤——切稳定期会把错误事件砍到 ~40%、系数方差放大约 1.5 倍，而错误率的练习效应仅 +0.4pp/6 周，折算 <2ms/段在噪声下）。

当前快照：稳定期 = 序号块[38]（全局 ok 行 #5701）起、4 键 5861 + 3 键 1322 + 2 键 2163 trial（R=346ms）；测试集 4 键 1172 + 3 键 264 + 角点留出 432。**训练池 = train4 + train3 + train2**（3 键入训是段位块 L==3 维可辨识的前提，2026-09-21 起）。

**跨快照噪声带**：无选优环节 → 无选优抽签噪声；剩余波动仅测试集重洗（数据增长 → N 变 → seed 2024 permutation 重抽，~±1ms）。跨快照的"旧模型×新测试"对比不可用（训练池与对方测试集 ~80% 重叠 = 泄漏）。

**为什么用保留口径（B4b 剔除后）**：

1. **用途匹配**：当量表服务于编码方案评估与键位优化（相对排序）。被剔段是注意力中断，与键对难度无关、对候选编码近似同分布的加性噪声——计入指标只稀释难度信号，不提供方案设计信息
2. **训练分布一致**：按键时间表在 B4b 保留段上训练，保留口径测试集与之同分布
3. **错误成本已独立建模**：错误率 × 错误修正时间由 §4.6 显式承担；中断率属会话/状态变量，不是键位属性

全口径定位：**真实场景下界**——若要预测含走神的绝对打字时间，需另建中断率模型；两口径之差即中断段（测试 ~5%）的不可预测性代价。

> 误差必须用模型未见过的数据计算；段级验证泄漏（trial ICC 0.308）使段级验证乐观（§4.5），固定 trial 测试集才是干净口径。评估编码方案用保留口径的**相对排序**（排序不随口径变化），绝对 ms 数以本表为准。

### 5.4 前键条件的实证依据

段间隔按**键对类型 × 前键条件**分解（09-21 当前数据重算：稳定期全量 B4b 保留段 19237 段中位；量级与方向和早期全量口径一致）：

| 类型 | 空前（首段） | 有前键（中段） | 差 |
|------|------------|--------------|-----|
| 跨手 | 74ms | 105ms | **+31ms** |
| 同手异指 | 66ms | 150ms | **+84ms** |
| 同键重复 | 149ms | 154ms | +5ms |
| 同指异键 | 193ms | 202ms | +9ms |
| **混合平均** | **76ms** | **127ms** | **+51ms** |

所有类型的方向一致（有前键更慢——手打完上一键不回位），但**幅度按类型不均**（跨手 +31 到同手异指 +84ms）。这正是 2 键表不可修的原因：统一比例放大修不了"同手段被低估得更多"的结构性错位（实证见 §5.3；两键累加与条件模型在随机 4 键码上仅 16.9% 码对排序不一致——Spearman 0.860，且两键累加对 100% 的码低估）。

模型视角（当前部署按键时间表 S(∅,x,y) vs 平均 S(p,x,y)）：跨手 `fi` +35ms、同手异指 `wv` **+91ms**、同指同列 `az` +22ms、同键 `aa` +2ms——同手连续是前键条件最敏感的类型。

### 5.5 错误率结构实证

**段类条件的依据**：错误率随码内位置强烈爬升（段位 1 的 0.57%/0.89% → 段位 3 的 3.18%；2 键码是"没爬起来就结束"的短爆发，故角点最安全 0.57%），无上下文模型把位置平均掉——类盲模型角点类均值 1.91% vs 实测 0.57%，对 T₂ 角点条目**高估 10.4ms/条目**（高错误键对前 10% 达 22.7ms），且偏差与 P_err 成正比会扭曲 2 键简码排序。部署差异（类盲→段类，09-21 去交互项后当前数据）：T₂ 错误成本均值 14.9→4.5ms、T₃ 29.8→17.6ms、T₄ 44.7→48.3ms。

**段类重参数化（2026-09-19 落地）**：3 键数据暴露了旧四列签名的错分——3 键码第二段（短尾）与 4 键码第三段（长尾）共用一列，实测 1.20% vs 3.11%（p=0.005），组装期 T₃ 错误项因此系统性高估。重参数化后总当量变化：**T₃ 平均 −15.7ms/码**（尾项不再借 4 键尾段列）、T₂ +0.23ms（角点列校准 0.40%→0.43%，更贴实测）、T₄ −0.4ms；分解验证（09-19 数据）：六格拟合 D 由 10.17（df=2, p=0.006）降到 0.14（df=1, p=0.71）。**09-21 复核（3 键数据再增 347 trial 后）**：旧四类仍显著不足（D=8.87, p=0.012），部署五类仍充分（D=1.31, p=0.52）；c2 短尾格 22 错/1344、c4 长尾 376 错/11937，T₃ 错误成本 bootstrap 区间由 [9.3, 26.8] 收窄到 [13.8, 26.0]ms（09-19→09-21）。c2/c4 分裂检验随数据刷新：z=−3.08, p=0.0020（旧四列把这两格并成一列）；c1 首段内部 L3 段1 vs L4 段1 = 0.81% vs 0.92%（z=−0.42, p=0.67 可合并）。

**复杂度上限**（09-16 早间快照 693 错误时重跑，`实验/实验-错误率算法对比.py`）：键对独热+签名 5-fold AUC 0.684（负收益）、HistGBM 0.693 vs 签名逻辑回归 0.692——差 0.001 在折间噪声内，**瓶颈是特征信息量而非模型容量**（容量型第四次证伪）。已识别升级路径：错误项按后键身份细化（中段上下文 P 随 n 摆动，Fitts(b,n) 主导）；触发条件 = 错误事件攒到 ~1200 时两批复验系数稳定性再决定。

**键对难度参考**（稳定期 B4b 段中位）：跨手 92ms < 同手异指 116ms < 同键重复 152ms < 同指异键 198ms。

### 5.6 段位特征落地（2026-09-21）与 3 键入训

**已落地**：时间模型加段位块 φ19、按键时间表改按段角色 6 片、**3 键正式入训**（`train_all = train4 + train3 + train2`）。三项同批生效——段位块的 `L==3` 维只在 3 键样本上可辨识，两者不可分割。**错误率侧原本 09-19 就已按段位重参数化，但同日又按其监控结论删掉了交互项 γ（§4.6），故错误侧的最终形式是纯加法 `β·有后键 + δ·(段位−1)`。**

**为什么**：段身份 (p,a,b,n) 只编码「是否首段 / 是否末段」，同一签名在 3 键与 4 键码中角色不同（3 键 seg2 与 4 键 seg3 同签名「有前键,无后键」）。旧单表把两者塞进同一格，代价是 **T₃ 系统性低估**：旧协议（3 键全留出）实测 T₃ 偏差 **−7.06ms**（`实验-三键时间偏差.py` 时代口径 −7.3~−8.7ms），分解到段 = 首段 −1.6 / **末段 −5.7**（低估集中在码末段）。而单纯把 3 键塞进训练只值 **+0.3~0.4ms** → 缺的不是数据量，是**特征里的角色信息**。

**受控分解（同一 φ15 B4b 掩码、同一留出 trial，2×2）**：

| 配置 | T₄ 总MAE | T₃ 总MAE | T₃ 偏差 | T₂ 段MAE |
|------|---------|---------|---------|---------|
| φ15，3 键不入训（旧协议） | 36.03 | 32.31 | −7.06 | 14.73 |
| φ15，3 键入训 | 36.09 | 31.94 | −8.07 | 14.73 |
| **φ19，3 键入训（新协议）** | **35.59** | **30.46** | **−5.30** | 14.62 |

→ φ19 的受控效应：**T₄ −0.50ms、T₃ −1.48ms、T₂ 持平**（与落地前的对照实验三刷一致：T₃ −1.2~−1.6 显著、T₄ −0.3~−0.5、T₂ 恒零）。

**落地后的快照与判读**（§5.2）：T₄ **36.1ms（对旧快照 36.0 持平）**、T₃ 留出首次可评 **30.4ms / 偏差 −4.9ms**、T₂ 14.6ms。三点必须一起看：① 受控配对说 T₄ −0.50ms，但**落地快照只显示持平**——因为 B4b 掩码的特征集随之改为 φ19，重选了保留集（完整 trial 1030→1032），两者不可直接比；0.5ms 在测试重洗带内，**不构成"为了 T₄ 而采纳"的理由**；② 真正的收益在 T₃：偏差从 −7.1 收到 −4.9ms（受控口径 −8.1→−5.3），这是下游 `equivalent_ms.prefix_t3`（calc-schema）实际在用的量；③ 残留的 T₃ 偏差形状**换了位置**——现在几乎全在**首段 L3i1 −4.0ms**（短尾 L3i2 已降到 −0.7ms），说明 3 键首段（3 键码的第 1 段）仍系统性偏快，下一轮若继续追应从这里入手（§5.7 给了它需要的数据量）。

**产物结构变化（version 2 → 3 / 4 → 5）**：`按键时间表.npz` 由单表 F(31,30,30,31) 改 6 角色片（918,900 条 vs 864,900）；`段当量表.npz` 由 5 片（错误段类）改 6 片（**段角色**，因为时间侧 L3i1 与 L4i1 已不同而错误侧两者仍同属 c1——错误率侧 09-19 已按段位重参数化，本次无需改动）。漂移量：4 键片几乎不动（|Δ| 2.5-4.0ms、均值 Δ≈0），**3 键片拿到自己的值**（短尾 vs 旧借用的长尾片 |Δ| 9.95ms、均值 +2.4）；码级 T₃ |Δ| 10.2ms、T₄ 6.4ms，Δ 的系统性成分 ≤3.5%、排序 ρ 0.94-0.99（随机重排，方案排序不受影响）。`总当量-2-4键.txt` 格式与码序未变（下游 calc-schema 读取口径不变）。

### 5.7 数据充分性：还要采多少（2026-09-21）

## 6. 讨论

### 6.1 局限性

- **串行假设**：段模型假设相邻击键串行。Dhakal et al. (2018) 显示熟练打字员 40-70% 的按键存在 rollover（重叠 30-100ms）——逐段求和可能系统性高估极快打字状态。实测（key-up 字段，释时全>0 无偏口径 10041 行，09-21 重算）：重叠比例首段 68.2%、中段 19.0%、尾段 48.0%，幅值中位 28-45ms，与文献区间一致——重叠集中在首段（静止启动加速期）与尾段（提前规划收尾），中段低重叠支持"段模型对中段串行假设最可靠"
- **字母身份残余效应**：刺激以字母呈现，拼音二元组熟悉度对键对耗时存在超出几何/手指特征的小效应（早期全量口径实测）——偏相关 −0.08（控制 φ8 与两键基线后），高熟悉键对比零熟悉约快 7-9ms，与表条目噪声同量级、远小于当量主效应。曾考虑改用键位图显示消除字母层，评估为弊大于利（打字技能按字母组织，位置刺激退化为找键认知任务）——维持字母显示
- **时间漂移（练习效应）**：采集期速度单调提升（早期 session 中段中位 208→157ms，-24.5%），且**按键对类型不均**（同指 -60ms > 同手 -42 ≈ 跨手 -39 > 同键 -13ms）——混期当量表对当前状态的难键对成本系统性高估。处理：**稳定期口径已落地**（§5.1 边界方法自动确定稳定期，训练/测试/部署均只用稳定期数据）
- **误差重尾**：飞行时间近似 log-logistic（重尾），沉思停顿可达数秒；B4b MAD 剔除处理了异常，但纯 MAE 对重尾敏感（可考虑分位数目标）
- **单用户**：模型为个人指法特征（含小指弱势等个体差异），人群外推需 136M Keystrokes 类数据验证

### 6.2 未来工作

（精度类扩容已证无收益，§5.2；下列均为非精度目标或远期条件性条目）

- **外推口径评估**：按三元组留出评估按键时间表外推误差——当前全局 MAE 掩盖了"2/3 条目零样本"的风险分布
- **人群先验**：136M Keystrokes 数据集（168k 人，公开免费）可作稀疏键对的先验/外部验证
- **rollover 显式建模**：key-up 字段已有——串行求和在高重叠段系统性高估，可按重叠类型修正整串口径
- **三元组交互**：Carpalx 的 k1:k2:k3 = 60:30:10 结构提示跨键对涌现惩罚，但三元组覆盖不足下三阶参数只会过拟合——数据量达标后再议
- **错误率数据积累**：~5-10 万 trial 后可升级 26 类指对嵌入/目标指难度特征（当前类别自由参数全部过拟合）

## 7. 结论与应用

本项目将击键时间成本建模从"2 键当量逐对累加"推进为"个人数据驱动的对称条件段模型"：段 S(段角色,p,a,b,n) 统一覆盖 2/3/4 键当量（同源同尺度，2026-09-21 起含段位/码长角色），错误成本按段类内含于"当量"定义。固定 trial 测试集上 4 键总时间 MAE 36.1ms、R² +0.683、排名精度 0.811；新建的 3 键留出指标 T₃ 30.4ms（偏差 −4.9ms）——绝对标定近完美（×k₄=1.005），且在 4 码/2 码两项上分别领先群体两键当量表 34%/55%（§5.3）。模型已贴实测噪声量级（§5.2），当前精度的剩余空间属组内生理噪声；后续条件性增益路径只剩两条：3 键首段残留偏差（§5.6/§5.7 给了数据量）、错误率模型的后键身份细化（中段上下文 P 随 n 摆动，错误事件 ~1200 时复验，§5.5）。错误率模型的交互项已按监控结论删除（§4.6），结构收敛为纯加法。**采集现状**：09-18 曾定档停采（52 session / 14017 行），当日因 3 键错误率隐患重启补采；09-21 段位特征落地后按数据充分性实测把混采比例重定为 **3 键 50% / 4 键 30% / 2 键 20%**（§5.7），**目标是把 T₃ 族这一项固定欠账（+1963 三键 trial ≈ 7.9 场）结清后回到「定档停采」**。本文数字与全部产物为 09-21 快照（58 session / 15960 行）。局限性（串行假设、字母身份残余效应、单用户）见 §6.1。

应用方式（应用域 = 4 码内词内评估，§4.8）：

- **编码方案评估**：将方案的常用编码代入总当量-2-4键.txt（错误成本已内含），计算平均击键总时间
- **键位优化**：调整个别键位映射后重新计算总当量，评估优化效果
- **键盘布局设计**：评估新布局的运动学效率（注意模型为 QWERTY 30 键采样训练，非 QWERTY 布局需重新采样）

### 产物分发（2026-09-22 定：产物不由 git 管理）

产物七件 (~20MB) 每次数据刷新整体换新、历史产物无参考价值，且本机网络对 GitHub 附件/HTTPS 不可靠
（见下）——故**产物彻底不入 git、不发布**：**只在本机 OneDrive `击键测速/产物/` 保留最新一份**，
下游（calc-schema 等）直接读该目录。主仓库只放代码 + 采集数据 + 本文档（克隆 3.8MB / `.git` 2.6MB）。

演进记录（供查证）：09-06 产物首次入库 → 09-18 曾决策「最终快照随仓库分发」→ **09-21 用
`git filter-branch --index-filter 'git rm -r --cached --ignore-unmatch 产物'` 自全部 40 个提交剔除
并 force-push**（`.git` 25MB→2.6MB，`.gitignore` 加 `产物/` 规则作安全网）→ 同日试过 GitHub Release
附件与独立产物仓库两条通道 → **09-22 用户决策「产物不需要用 git 管理，本机保留最新产物就行」，
两条通道全部废弃**（`sync_github.py` 只同步代码 + 数据）。

**本机网络实测（2026-09-21，跨项目通用）**：① `release-assets.githubusercontent.com` 不可靠 ——
上传端 gh 对非 ASCII 附件名会退化成 `default.npz`，下载端 2 次测试 1 次 TLS handshake 超时、
1 次**静默截断**（只下到 3.6MB / 应有 12.4MB）；② HTTPS 访问 github.com 被 reset
（`Recv failure: Connection was reset`）→ **一律用 SSH 远端**；③ git(SSH) 推 12-20MB 稳定。

**注意**：主仓库 history 已于 09-21 重写，其它机器上的旧克隆需重新 clone（不能 pull）。
