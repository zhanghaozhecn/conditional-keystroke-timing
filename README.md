# 击键测速 — 条件击键当量建模

**条件击键当量**（Conditional Keystroke Equivalent，简称"当量"）：从个人打字测速数据中学习**前键条件下**键位间的击键时间成本（ms，非物理距离），输出段当量母表与 2/3/4 键当量表，用于输入法编码方案评估与键位优化。

**摘要**：传统键位成本模型用 2 键当量逐对累加，假设"打完一个键手就回位"。实测表明该假设系统性低估整串耗时，且低估幅度按键对类型不均（跨手 +42ms → 同手异指 +80ms）——用其评估编码方案约 20% 的排序会被扭曲。本项目以"前键条件段"为单位建模，并已对称化（2026-08-29）：每段时间 `S(p,a,b,n)` 同时以前两键 `p,a` 与**后继键** `n` 为条件（后继键准备成本，段位效应 §6.5/§6.6），整串成本 = 段之和。在固定 trial 测试集上（稳定期内 20% 留出，无泄漏），模型总时间 MAE 46.6ms（R² +0.542；练习漂移段已按边界方法剔除，§5.1）、排名精度 Spearman 0.706，优于仅用两键数据训练的同结构模型累加与传统逐键对均值表累加（§5.2）。

---

## 1. 背景与动机

键盘输入的成本建模是编码方案评估与键位优化的基础。传统做法（Carpalx、KLA 类工具）使用**2 键当量表** B(a,b)——键对 (a,b) 的击键时间——逐对累加估算整串耗时：

```
T'(abcd) = B(a,b) + B(b,c) + B(c,d)
```

其隐含假设：**键对间独立，打完一个键后手回到静止起始位置**。这一假设在两个层面失实：

1. **中间键对的前键从不是"空"**：打完 `r` 后手指停在 `r` 位，直接击打 `w` 的起点不是 home 位。Rumelhart & Norman (1982) 的击键时序模型早已指出相邻间隔互为条件（"间隔负相关"），且上一键准备完成后可直接启动下一键（不回位）。
2. **低估幅度按键对类型不均**：前键条件下的中段比空前键首段慢（跨手 +42ms、同手异指 +80ms），差异随类型不同——用统一比例修正不了，排序被结构性扭曲。

**条件击键当量**直接建模 `S(p,a,b,n)` = "前两键为 p,a 时击打键对 (a,b) 的时间（含后继键 n 的准备成本）"，整串成本 = 段之和：

```
T(abcd) = S(∅,a,b,c) + S(a,b,c,d) + S(b,c,d,∅)
```

2 键表是段模型在空前键（∅）+无后继（∅）下的特例切片——2/3/4 键当量同源同尺度，完全自洽。

## 3. 数据采集

### 3.1 采集协议

`python 当量采集工具.py`（tkinter GUI）：显示随机编码，录入真实击键时间戳。

**2/4 键混采（2026-08-29 起）**：每试次以 P2=0.30 概率出 **2 键码**（其余 4 键）。2 键试次服务对称段模型的 T₂ 角点 S(∅,a,b,∅) 验证（§6.6）——4 键试次的首段总带真后键，该"词首+词尾"组合只能靠 2 键试次直接测量。2 键与 4 键各用**独立的欠样本键对池**：4 键池喂段覆盖，2 键池喂 900 键对的角点覆盖；2 键行 code 长度 2、c_d/d_d=0 填充，下游按 `len(code)==4` 过滤，旧流程不受影响。

| 操作 | 行为 |
|------|------|
| 输入显示的 2/4 个字符 | 正常打字 |
| 输错（任意键） | 立即变红停止，进入随机延迟 |
| 空格 | 跳过当前组（不记录），进入随机延迟 |
| Esc | 退出 |

**采样策略（多样性加权）**：首键均匀随机，后续键按 `w(b|a) ∝ 1/(n(a,b)+1)` 加权——欠样本键对优先（符号键 `;,./` 零样本时自动补足），键对样本量趋均衡后自动回归均匀随机。每次试次结束（正确/错误/跳过统一）延迟 **300-800ms 随机**再显示下一组，打断固定节律，防止"预期性击键"把键对难度差异压缩平均。

## 4. 方法

### 4.1 问题定义

给定 4 字符编码 `abcd`，预测击键总时间 T（ms）。训练数据每行记录一个随机 4 字符串的实际击键时间戳。

### 4.2 对称条件段模型（v2, 2026-08-29 落地）

将序列拆成**三段**，每段独立预测，**前两键 + 后继键**共同条件（对称段模型 `S(p,a,b,n)`，采纳依据 §6.6）：

```
每段 t = 双线性交互(e) + MLP(e, φ15)   S(p,a,b,n) ≈ e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b + MLP(75→64→1)
  前键空/无后继 = 索引 30（∅）
  φ15 = φ8(a,b) 几何 + φsuc7 后键特征 [存在, 同手(b,n), 同指(b,n), 同键(b,n), Fitts(b,n), 同手(a,n), Fitts(a,n)]
  n=∅ 时 φsuc 全 0 (存在位=0); n 仅经特征进入 (实验: 几何身份≈嵌入身份, 5 双线性无增益)

整串当量统一公式 (n 键序列 k₁k₂...kₙ, k₀ = k_{n+1} = ∅):
  T_n = Σ_{i=1}^{n-1} S(k_{i-1}, k_i, k_{i+1}, k_{i+2})    首段前键=∅, 末段后键=∅

  两键  T₂(ab)   = S(∅,a,b,∅)                                        ← 1 项 (角点, 2 键试次验证中)
  三键  T₃(abc)  = S(∅,a,b,c) + S(a,b,c,∅)                           ← 2 项
  四键  T₄(abcd) = S(∅,a,b,c) + S(a,b,c,d) + S(b,c,d,∅)              ← 3 项
```

v1 → v2 变更仅 MLP 输入 68→75 (+448 参数), 双线性/嵌入结构不变; 增益: 总 MAE −1.3~−1.6ms (两组独立 best-of-10 方向一致), 且段位效应 (§6.5) 作为 n=∅ 存在位被模型自然收编。

### 4.3 为什么前键条件（实测证据）

段间隔按**键对类型 × 前键条件**分解（15440 段，B4b 剔除后）：

| 类型 | 空前（首段） | 有前键（中段） | 差 |
|------|------------|--------------|-----|
| 跨手 | 95ms | 138ms | **+42ms** |
| 同手异指 | 105ms | 185ms | **+80ms** |
| 同键重复 | 153ms | 157ms | +4ms |
| 同指异键 | 202ms | 226ms | +24ms |
| **混合平均** | **111ms** | **164ms** | **+53ms** |

所有类型的方向一致（有前键更慢——手打完上一键不回位），但**幅度按类型不均**（跨手 +42 到同手异指 +80ms）。这正是 2 键表不可修的原因：统一比例放大修不了"同手段被低估得更多"的结构性错位（实证见 §5.2）。

模型视角（段表 S(∅,x,y) vs 平均 S(p,x,y)）：跨手 `fi` +15ms、同手异指 `wv` **+105ms**、同指同列 `az` +59ms、同键 `aa` +28ms——同手连续是前键条件最敏感的类型。

### 4.4 模型结构

输入四元组 `(p, a, b, n)` 中三键 `(p,a,b)` 经**共享嵌入**与**交互部分**两条路径汇合后加 MLP 头，后键 `n` 经 φsuc7 特征进入 MLP（sym_phi 形式）。两种架构（`--model bi|cp`）仅交互部分不同，验证集误差小者胜出（当前双线性 de20/dh64 为默认）。

```
输入: ids = [p, a, b, n]（31 索引, n 仅经 φ 生效）, φ15 = φ8(a,b) + φsuc7(b/a, n)
共享: e_p, e_a, e_b = E_key[ids[:, :3]]   E_key ∈ ℝ³¹ˣ²⁰（30 键 + ∅）
```

**① 双线性 + MLP（默认 `--model bi`）**——两两配对交互：

```
S(p,a,b,n) = e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b  +  MLP([e_p; e_a; e_b; φ15])
```

| 组件 | 形状 | 说明 |
|------|------|------|
| W₁/W₂/W₃ | 3 × (20×20) | 显式二阶交互：前键×首键、首键×次键、前键×次键 |
| E_key | 31×20 | 通用键位嵌入（与 W 共享同一套嵌入） |
| MLP | 75→64→1 (ReLU + RMSNorm) | 非线性残差（含 φsuc 后键特征） |

**② CP 张量分解（备选 `--model cp`）**——三向联合交互：`S = Σ_{r=1}^{32} U(p)_r·V(a)_r·W(b)_r + MLP(...)`，v2 下后键经 e_n 并入 MLP 头。历史：双线性扩容前 CP rank=32 曾最优（66.1/0.402），扩容后验证集 R² 0.395 vs 0.343 被反超，降为备选。

**架构选型结论**（5 seed 验证集口径，详见 4.6）：扩容双线性整体优于 CP（MAE -2.6~-3.7，R² +0.04~+0.08）；继续加大参数（de24/dh96 起）过拟合或方差过大——平衡点 de20/dh64（v2 对称模型 6813 参数）。

### 4.5 键位嵌入与交互特征

键盘为 **3 行 10 列完整 QWERTY（30 键）**：26 字母 + `; , . /`。每键独立可学习向量 `e_k = E[k]`。当量定义：**期望键对耗时，单位 ms**（模型预测原始值；2026-08-19 起废弃"除以最快速字母键对"的相对归一化方案——原归一化限定字母键对是为避免符号键污染最小值，现在不再需要）。

键位嵌入本身不含手指归属信息，显式注入 8 个文献特征：

```
φ(a,b) = [same_hand, same_finger, same_key, col_dist, row_dist, fitts,
          mirror_pair, cross_row_same_finger]

same_hand(a,b)  = 1  如果 a 和 b 在同一只手（左手=col 0-4，右手=col 5-9），否则 0
same_finger(a,b)= 1  如果 a 和 b 用同一根手指按下，否则 0
same_key(a,b)   = 1  a==b 同键重复（零幅移动需单独建模, 不适用 Fitts）
col_dist / row_dist  = |列差| / |行差|（İşeri & Ekşioğlu 2015: 列>行>手 重要性）
fitts(a,b)      = log2(1 + √(col² + (2·row)²))   Fitts 对数项, W=键宽, 行距≈2 键宽
mirror_pair(a,b)= 1  异手对称手指（Grudin 1983: 换位错误集中于镜像手指）
cross_row_same_finger(a,b) = 1  同指跨行（keygen: 同指顶↔底行最慢最易错）
```

**消融结论**（两轮）：逐特征 leave-one-out 全部持平（Δ<0.2ms，seed 方差 ±1ms）——φ 特征间互为冗余；但**整体删除损失 +1.7ms**（§6.4 无泄漏测试口径）——φ 作为整体提供嵌入补不上的几何先验，价值在稀疏三元组外推（2/3 段表条目零样本），LOO 在训练分布内做所以测不出。保留 φ8 由"文献可解释性"升级为实证支撑。

### 4.6 训练

- **目标**：批量 MSE（段级），验证集 20%，早停 patience=60，Adam lr=0.001
- **best-of-N 选优（`--trials`，默认 10）**：同参数训练受随机初始化 + 随机划分影响，验证集段 MAE 波动 ~±2ms（R² ±0.12）。训练 N 次、用**验证集段 MAE** 选最强（选优不能用全数据——含训练集会偏向过拟合）
- **可复现性（2026-08-18 起）**：`击键模型.py` 导入时固定运行环境（`torch.set_num_threads(1)` + `torch.manual_seed(0)`）。此前新进程的 torch 默认 RNG 为熵播种、模型构造（嵌入/线性层初始化）依赖它，而 `train(seed)` 只重播轨迹不重播构造——这是"同命令重跑结果漂移"的主因（±1.4ms 报告波动的很大一部分）。现在同代码+同数据**跨进程逐位可复现**（各变体 best-of-N 的初始化沿确定性流推进，仍互不相同）；单线程对此规模模型还快 ~20%。历史表数字与新固定值差异均在原噪声带内
- **验证集泄漏（2026-08-14 实测）**：同一 trial 的三段共享个人速度因子（trial ICC 0.308，段间相关 corr(t₁,t₂)=0.690、corr(t₂,t₃)=0.844），段级随机划分使验证集与训练集共享 trial——验证段 MAE 系统性偏乐观约 9ms（33.5 vs 42.6，21%）。best-of-N 选优沿用段级验证（主流程未变），但**模型对比与报告口径必须用 trial 级留出**（固定 20% trial 测试集，测试 trial 的段不进训练/验证），见 §5.1 口径矩阵
- **异常剔除（B4b 两阶段残差，键对分桶）**（2026-08-12 落地，替代单阶段 MAD；开发链实验脚本已删除，结论存档本节与 `击键模型.py` docstring）：
  1. 段位置分桶 MAD k=3 剔除 → 训练 M0（5 seeds 验证集选优，干净模型提供"期望行为"）
  2. M0 推全数据 → 带符号残差 `y−ŷ`（正 = 比预期慢）
  3. 残差按**键对 (a,b) 分桶**、**单侧上围栏**（r ≥ med + 3·1.4826·MAD）剔除——键对系统性偏差中心化后只删"比该键对合理预期慢"的段（真注意力中断）。**方向语义（2026-08-20）**：异常只可能偏大——注意力中断只拖慢不拖快，打得比预期快是 rollover/预备连击（真实打字行为）不删；原 |残差| 双侧判据曾把 16%（全量）/35%（测试集）的删除错放快侧，单侧化后修正
  - 依据：全局残差法会把"比模型预测慢"的真实慢段当异常删——模型学不会的难键对（pq 跨手双小指）17 段删 7 段，当量 162→95ms 失真（用模型偏见定义正常，循环论证）；键对分桶修复后当量恢复。固定测试集终局对比各方案 44-47ms 在噪声内——剔除收益在**当量稳健性**（防中断段拉偏键对当量）而非预测精度。剔除率 ~4.8% 在文献范围（van Selst & Jolicoeur 1994 n 依赖法调研，5-10% 常见）
  - 验证：合成注入 +300ms 真异常 100% 检出（recall），误删率≈基线剔除率；剔除集 5 M0 seed Jaccard 0.977（结构性稳定）
- 段样本：每 trial 3 段（t₁: 空→ab, t₂: a→bc, t₃: b→cd），共享 MLP 头，段间互相增强

### 4.7 设计边界

- ❌ **字母 N-gram 频率**：不引入自然语言熟悉度偏差，纯随机采样
- ❌ **连组模式**：每组独立开始（模拟分词间自然停顿），不建模组间转移
- ❌ **节奏/节拍器**：随机延迟打断节律，按"打对条件下尽可能快"测试
- ❌ **变长编码**：仅测 4 字符编码（2/3 键当量为段表切片组合）

## 5. 结果

### 5.1 模型精度（B4b 剔除，固定 trial 测试集）

**统一口径（2026-08-30 起）：稳定期内固定 trial 测试集**（用户决策；此前 08-19 起为全量混合划分——练习漂移段使模型对当前状态系统性偏慢 ~12ms，§6.7，两口径数字不可比）。`stable_split`（击键模型.py）边界方法：每 session 正确 4 键 trial 总时中位 → 3-session 滚动中位平滑 → R = 末 5 个平滑值中位 → 自末向前最早连续满足 平滑值 ≤ R×1.10 的 session 起（确定性无随机，抗单 session 异常）；稳定期内 seed 2024、20% trial 留出，训练/评估只作用于训练侧（训练集 B4b + best-of-10），测试集独立 B4b（内部自训 M0，与训练无信息交换）。`python 击键模型.py` 直接输出（确定性流，重跑必得同值）。**部署模型同用稳定期全量**（当量表 = 当前状态语义）。**例外：错误率模型（分析-错误率规律.py）仍用全部数据**（错误率按用户决策不随练习过滤）。**全数据（含训练集）口径已废弃**（训练集评估偏差实测 +14.3ms，系统性乐观）。

| 口径 | 段 MAE | T₄ 总 MAE | R² |
|------|--------|-----------|-----|
| **保留口径**（测试集独立 B4b 后——**本研究唯一默认指标**，理由见下） | 28.1ms | **46.6ms** | **+0.542** |

当前快照：稳定期 = session[29] 起 14/43 session、trial 3718/9529（R=351ms、带=×1.10）。稳定期口径消除了练习偏移后指标大幅改善（混合口径末值 59.7/+0.456 → 46.8→46.6/+0.531→+0.542，与 §6.7 预测 ~48.5 吻合）——此前历轮混合口径数字与本表不可比。

**跨快照噪声带（2026-08-29 候选全检实证）**：best-of-10 的 10 个候选在同数据同划分的留出测试上总 MAE 落 66.3~69.3（中位 67.3、极差 3ms），验证段 MAE 与测试 MAE 的秩相关在单抽签内可为负（该抽签 −0.61——va 最优候选恰为测试最差）——**标题数字含选优方向 ±2ms 的抽签噪声**，叠加测试集重洗效应，相邻数据快照间数字波动 ±3ms 属正常（处置 = 接受噪声带，方案对比看相对排序）。跨快照的"旧模型×新测试"对比不可用——两次快照的训练池与对方测试集约 80% 成员重叠（泄漏）。部署表不受选优运气影响（部署模型独立选优）。数据扩容是标题数字的长期下行驱动力：N=7073 快照 69.3 → N=7593 62.5 → N=8114 63.3 → N=8666 59.7（扩容继续有效但快照间含噪声带波动）。练习漂移的分布偏移另见 §6.7：对**近期状态**预测，过滤前期数据再省 −10~−12ms（混合测试集测不出该效应）。

**为什么用保留口径（2026-08-26 起默认只展示保留口径，全口径需特别说明）**：

1. **用途匹配**：当量表服务于编码方案评估与键位优化（相对排序）。被剔段是注意力中断，与键对难度无关、对候选编码近似同分布的加性噪声——计入指标只稀释难度信号（拉低 R²），不提供方案设计信息
2. **训练分布一致**：段表在 B4b 保留段上训练（中断已剔除），保留口径测试集与之同分布（稳定打字状态）；全口径测的是模型从未学习、也无需学习的环境冲击
3. **非运动成本已独立建模**：错误成本由期望当量（500ms×P_err，§5.3）显式承担；中断率属会话/状态变量（随练习进程漂移），不是键位属性，不应混入当量指标

全口径定位：**真实场景下界**——若要预测含走神的绝对打字时间，需另建中断率模型；默认不报告，两口径之差即中断段（测试 ~5%）的不可预测性代价（被剔段段 MAE ~158ms、R² 为负）。

> 评估口径说明：误差必须用模型未见过的数据计算；段级验证泄漏（trial ICC 0.308）使段级验证乐观（§4.6），固定 trial 测试集才是干净口径。2026-08-18 起运行环境固定（单线程+播种，§4.6），同代码+同数据重跑逐位一致；历史轮次数字（57.3/+0.519、71.6/+0.338、71.3/+0.316、86.2/+0.243 等）与本表差异均在剔除方案演进（双侧→单侧 2026-08-20）与噪声带内。评估编码方案用保留口径的**相对排序**（排序不随口径变化），绝对 ms 数以本表为准。

### 5.3 错误转当量

一次按键错误的时间成本 = 退格 + 注意力重定位 + 重输 ≈ **固定 500ms**（数据推导 ~455ms：错键段 160-221 + 退格 180 + 重打首键 102），与键对运动难度解耦。评估编码时把"打错"的期望成本计入：

```
期望段当量 = 段当量 S(p,a,b,n) + 500ms × P_err(a,b)
整串期望   = Σ 期望段当量（加性保持）
```

**键对错误率模型**（`分析-错误率规律.py`，9 特征逻辑回归，17032 键对事件 / 323 错误，5-fold AUC 0.620±0.039）：

```
P_err(a,b) = σ(−4.273 + 0.484·同手 − 1.873·同指 + 2.243·同指同列
             + 0.375·无名-中指 − 0.013·小指-无名 + 2.149·同指双列
             + 0.356·b左小指 − 0.420·b顶行 + 0.262·b底行)
```

特征全为键位可计算量（`同手/同指` 手位关系、4 个坏指对、`b左小指` 及目标键行）。原始统计级错误率噪声大（每键对仅 ~15 样本），模型输出受特征结构约束更稳。系数是正确率模型取反——`同指` 负系数因含同键重复（0.2% 低错）拉低，坏子类由坏指对特征单独暴露。

**键对难度参考**（段间隔，15440 段）：跨手 124ms < 同键重复 156ms < 同手异指 159ms < 同指异键 218ms。

## 6. 讨论

### 6.1 局限性

- **串行假设**：段模型假设相邻击键串行。Dhakal et al. (2018) 显示熟练打字员 40-70% 的按键存在 rollover（重叠），重叠 30-100ms——逐段求和可能系统性高估极快打字状态。实测（key-up 字段，2026-08-14）：重叠比例首段 56.6%、中段 10.8%、尾段 37.0%，幅值中位 35-43ms，与文献区间一致——重叠集中在首段（静止启动加速期）与尾段（提前规划收尾），中段低重叠支持"段模型对中段串行假设最可靠"
- **字母身份残余效应（2026-08-20 实测）**：刺激以字母呈现，拼音二元组熟悉度对键对耗时存在超出几何/手指特征的小效应——偏相关 −0.08（p=0.03，控制 φ8 与两键基线后），高熟悉键对比零熟悉约快 7-9ms，与表条目噪声（标准误 ~11ms）同量级、远小于当量主效应（同手异指 +80ms）。单侧剔除已过滤"难读串中途回看"的慢侧成分，残余为熟悉组块的加速（快侧，按语义保留）。曾考虑改用键位图显示消除字母层，评估为弊大于利（打字技能按字母组织，位置刺激退化为找键认知任务）——维持字母显示，熟悉度如需处理在应用层校正
- **时间漂移（练习效应，2026-08-14 实测）**：采集期（07-24→08-11）速度单调提升——session 中段中位 208→157ms（-24.5%，Spearman ρ=-0.79），错误率无变化（真技能提升）；08-08 后进入平台期（145-167ms）。漂移**按键对类型不均**（同指 -60ms > 同手 -42 ≈ 跨手 -39 > 同键 -13ms），相对难度结构也在漂移，混期当量表对当前状态的难键对成本系统性高估。处理：当前维持全量训练；稳定期数据攒足（~2500-4000 trial，键对覆盖回满 + 样本中位 ≥5）后**删除前期数据、纯稳定期训练**（时间归一化已测不落地——过渡收益在噪声内，实验脚本已删、结论存档）
- **误差重尾**：飞行时间近似 log-logistic（重尾），沉思停顿可达数秒；MAD 剔除处理了异常，但纯 MAE 对重尾敏感（可考虑分位数目标）
- **单用户**：模型为个人指法特征（含小指弱势等个体差异），人群外推需 136M Keystrokes 类数据验证

### 6.2 文献特征消融（2026-08-11）

错误率模型侧：镜像手指/跨行同指/相邻手指/方向不对称 4 个文献特征**无增益**（13 特征 AUC 0.619 ≈ 9 特征 0.620）——与现有坏指对高度共线。分层确认：镜像手指在本数据是**保护项**（2.87% < 非镜像 3.86%——Grudin 的换位错误占比 ≠ 键对风险）；b 离拇指侧更易错（5.16% vs 3.87%，Lachnit 方向不对称确认）。双向计数（错键事件并入）AUC 降至 0.600 但错误事件翻倍、校准更稳（`--dual` 开关保留）。

### 6.3 未来工作

- **数据扩容（第一优先级，但目标是指标换位）**：学习曲线实测（`实验-学习曲线.py`，852→3640 trial）：段 MAE 47.0→43.3，幂律下界 41.8——**模型 MAE 已饱和**（距下界仅 1.5ms，加数据不再有可见精度变化）；数据价值转向**当量表条目质量**：键对样本中位 6（当量标准误 ~11ms）→ 4× 数据（~22,000 trial）标准误减半；段三元组覆盖 33.4% → 1.8× 数据（~10,000 trial）覆盖翻倍。采样策略向稀疏三元组倾斜（多样性加权已有，可强化）
- **外推口径评估**：按三元组留出（hold-out）评估段表外推误差——当前全局 MAE 掩盖了"2/3 条目零样本"的风险分布
- **人群先验**：136M Keystrokes 数据集（168k 人，公开免费）可作稀疏键对的先验/外部验证
- **rollover 显式建模**：key-up 字段已有，实测重叠比例首段 56.6%/尾段 37.0%（幅值中位 35-43ms）——串行求和在高重叠段系统性高估，可按重叠类型修正整串口径
- **三元组交互**：Carpalx 的 k1:k2:k3 = 60:30:10 结构提示跨键对涌现惩罚，但三元组 33.4% 覆盖下三阶参数只会过拟合——数据量达标后再议
- **错误率数据积累**：~5-10 万 trial 后可升级 26 类指对嵌入/目标指难度特征（当前类别自由参数全部过拟合）

结论：**现有元素全部有实证支撑，无一项可无代价删除**：

> **复现性备注（2026-08-18 固定流重跑，同协议 7 变体 × 10 trials）**：目标函数结论稳固复现（l1 +2.5ms/R²+0.190、huber50 +1.5ms/R²+0.207，MSE 保留无疑）；**结构变体间差全部落入 ≤1.6ms 且排序与上表不同**（bi_only 84.6 最好、no_w3 -0.3 持平）——best-of-10 的选优噪声（±1-2ms）主导结构变体间差，上表的结构排序（W₃ 最值钱等）对 best-of-N 抽样敏感，未在固定流下复现。结构取舍如需定论应提高 `--trials`（20+）。下表保留为历史轮记录：

- **W₃ 跨键双线性**（前键×次键）是单位参数最值钱的组件（400 参数 = +2.1ms）——跨越中间键的运动规划有直接信息，此前怀疑其冗余被推翻
- **φ8** 整体删除损失 +1.7ms。此前的逐特征 LOO 消融持平（Δ<0.2ms）只在训练分布内成立——特征互为冗余（删一个别人顶上），但作为整体提供嵌入补不上的几何先验；其价值在**稀疏三元组外推**（2/3 条目零样本），正是段表最依赖的能力
- **双线性 vs MLP 头**：双线性（1200 参数）值 +1.7ms，MLP 头（4500 参数）仅 +0.5ms——参数效率悬殊，但删哪个都变差。bi_only 以 1/3 参数接近基线总 MAE，段级却差 2.8ms，段表质量优先故不压缩
- **目标函数**：MSE 保留（huber 噪声内持平、L1 恶化 R² 0.261→0.218）——"MSE 训 MAE 评"的错配不是问题
- **结构收敛判据**：模型残差 SD / 段固有噪声 SD = 0.91（同三元组重复测量组内 SD 中位 27.2ms）——已贴到任何模型无法突破的数据噪声下界，剩余结构空间 ~3ms 段级；性能提升靠数据扩容而非改结构

### 6.5 段位效应（2026-08-26，脚本已删、结论存档本节）

中段中位 ~150ms 明显慢于尾段 ~128ms，但两者输入结构相同（前键+键对、同分布随机采样）——差异只能来自**段在串中的位置**。实证：

- **效应量化（键对级配对，872 对两侧 n≥2）**：同一键对在中位比尾位慢 **+19.8ms**（中位更慢占 74% 对）；**随类型交互**——跨手 +25.8、同手 +22.9、同指 +5.4、同键 **−7.6**（反向）。机理：尾段是"甩出"的末键（无后继键需准备，rollover 重叠率 37.5% vs 中段 11%；含 §3.3 历史释时偏差，无重复字母子集约再 +3~5pp，方向不变），中段需同时准备下一键
- **部署模型残差的段位偏差**：统一模型对中段系统性低估（+7.0ms）、尾段系统性高估（−13.5ms）——平均化使两 slot 各错 ~10ms
- **三方案对比**（保留口径，best-of-10）：

| 变体 | 段MAE | 总MAE | R² | 段位分解（首/中/尾） |
|------|-------|-------|-----|---------------------|
| baseline（统一，现行） | 36.7 | **67.9** | **+0.338** | 31.0 / 39.6 / 39.3 |
| 统一+段位 one-hot | 35.4 | 68.6 | +0.313 | 30.2 / 38.5 / 37.5 |
| 分段独立模型 | **35.2** | 68.4 | +0.313 | 30.4 / 38.0 / 37.2 |

结论：
1. **段级预测段位感知更好**（段 MAE −1.3~1.5ms，三个段位均改善）；**整串预测无收益**（baseline 反而最优，差异在噪声带内）——每个四码恰好含一个中段+一个尾段，位置效应的主成分在三段求和中抵消，统一模型的"平均化"等效于 slot 偏移互消
2. **完全分段独立无额外好处**：各 1/3 数据的稀释抵消位置保真（与 φ8 的稀疏外推教训一致）；若需段位感知，"+3 输入维 one-hot"是即插即用选项（共享全部键位嵌入）
3. **应用域限定（2026-08-27）——当量的优化与使用仅限 4 码内**：当量的应用对象是 4 码二字词（2/3 码单字简码同表覆盖），打字时词与词之间自然存在分词间隔，**连续输入（跨词无间隔序列）不在建模与应用范围内**。该限定下，此前"尾段折扣可能是装置伪影"的警示失效：孤立 4 键试次的范式（词前有间隔、词内 4 键连击、词后是间隔）与真实二字词输入结构一致，尾段"甩出"就是词末键的真实成本结构，统一模型的中/尾 slot 偏差在 T₄ 求和中精确互消。仅当未来扩展到跨词连续序列评估时，才需要改用"位置=中段"的表语义

### 6.6 后键条件——对称段模型 S(p,a,b,n)（2026-08-27 实验，08-29 采纳落地）

动机：§6.5 段位效应机理"中段需预备后继键"提示**后键身份**也条件化当前段耗时 → 试验对称化 S(p,a,b,n)，n=后继键（尾段 n=∅，复用索引 30）。数据快照 N=7068（32→33 session），固定测试集保留口径，每变体两组独立 best-of-10（seed 0-9/10-19）穿透选优噪声（±1-2ms）。

**数据证据（弱）**：中段内同 (前键,当前键) 对分桶配对，后键同手 +5.0ms（56% 组更慢）、后键=当前键 +13.4ms（69%）、同指无效应——量级远小于前键条件（+42~80ms）。

**变体对比**（段MAE/总MAE/R²，两组批次）：

| 变体 | 段MAE | 总MAE | R² | Δ总 vs 基线 |
|------|-------|-------|-----|------------|
| baseline S(p,a,b) | 35.5 / 35.7 | 66.0 / 65.8 | +0.378 / +0.382 | — |
| slot9（φ8+存在位，纯段位） | 34.4 / 34.0 | 65.6 / 64.8 | +0.390 / +0.395 | −0.4 / −1.0 |
| sym_phi（φ8+后键几何 7 维） | 33.9 / 33.7 | 64.4 / 64.5 | +0.415 / +0.409 | −1.6 / −1.3 |
| sym_mlp（e_n 入 MLP，88 维） | 33.9 / 33.8 | 64.5 / 64.3 | +0.406 / +0.414 | −1.5 / −1.5 |

结论：
1. **增益真实可复现**：3 个对称变体 × 2 组独立批次方向全部一致——总 MAE −1.3~−1.6ms（−2.2%）、段 MAE −1.6~−2.0、R² +0.37→+0.41；信息在应用时合法可得（评估 T₄ 时全码已知）
2. **增益分解**：存在位（N=∅ ⟺ 尾段，= 段位效应换通道）贡献约 −0.4~−1.0；后键**身份**再贡献约 −1.0；几何身份 ≈ 嵌入身份（sym_phi ≈ sym_mlp，与弱身份证据一致——粗类型就够）；5 双线性（sym_full，8445 参数）无额外收益；学到的"后键存在效应" +21ms 与 §6.5 的 +19.8ms 段位效应独立互证
3. **语义影响**：T₃/T₄ 的全部查询点都在训练分布内（首段 n=真键、尾段 n=∅ 均有训练数据，纯内插）；**唯 T₂ 角点 S(∅,a,b,∅) 零样本外推**（首段总有真后键，该组合训练未现）——模型给出 T₂ 表整体平移 −19.6ms（Pearson 0.911）；语义上"孤立 2 键词无后继"更正确，但无 2 键试次数据可验证
4. **【已采纳 2026-08-29，sym_phi 形式】**：改动 = `build_tensors` 增后继键列 + φ 8→15 维（**模型结构完全不变**，+448 参数 → 6813）；φ_suc 7 维 = [存在, 同手(b,n), 同指(b,n), 同键(b,n), Fitts(b,n), 同手(a,n), Fitts(a,n)]，n=∅ 时全 0；查询公式 T₂=S(∅,a,b,∅)、T₃=S(∅,a,b,c)+S(a,b,c,∅)、T₄=S(∅,a,b,c)+S(a,b,c,d)+S(b,c,d,∅)。落地内容：
   - `击键模型.py` v2：段表导出 **npz 化**（`当量-段表.npz`，F (31,30,30,31) + 元数据，替代 v1 3-D 文本段表；npz=NumPy 压缩存档，加载毫秒级，仅供程序消费的内部母表——成品表仍为文本）；`keystroke_model.pt` 升 v2（与 v1 权重不兼容）
   - `组装当量表.py`：读 npz，按上述公式向量化组装；chai 差值表（`组装-chai当量表.py`）增加 **t4 校正 gram 层**——对称模型下旧 t2+t3 差值对 4 键码不再精确 telescoping（残差恰为后键效应），t4(abcd)=T₄−(t2 和+t3 和) 使 gram 和精确还原（--selftest 全量 837,000 式偏差 0）；错误损失（--expected）加在 Tₙ 层，差值中 P 项精确抵消、仅 t2 携带
   - 全链路重跑（首跑 N=7068：64.1/+0.418；当日 N=7073 快照重跑：69.3/+0.340，噪声带见 §5.1）
   - 3 键采集判定为不必要：T₃ 两段查询点均已有训练分布覆盖，3 键试次不产生新查询点
   - T₂ 角点政策：采集 2 键试次验证（§3.1 已混采）；对称模型全部查询点中唯 T₂ 角点 S(∅,a,b,∅) 无训练样本（特征空间内插）

### 6.7 练习过滤与错误率结构（2026-08-30，脚本已删、结论存档本节）

**练习过滤（前期数据是否该剔除训练）**：练习效应显著（40 session 总时 −29.9%、ρ=−0.90、幂律 466·n^−0.178+300，渐近线 300ms 当前 356ms 仍在上行）——早期数据来自"更慢的被试状态"。实验：测试集 = 最后 8 session 随机 20%（近期状态代表，n=315），训练池 = 去掉前 K 个 session（各 B4b + best-of-10，测试集独立 B4b）：

| 去前 K session | 训练池 trial | 池段中位 | 近期测试总 MAE | R² |
|------|------|------|------|-----|
| 0（全量） | 8338 | 125ms | 60.3 | +0.290 |
| 15 | 5295 | 116ms | 50.3 | +0.463 |
| 20 | 4071 | 113ms | 49.2 | +0.465 |
| 25 | 3251 | 111ms | **48.5** | **+0.474** |

结论：**过滤前期数据对"预测近期行为"收益 −10~−12ms MAE / R² +0.18**，远超噪声带，且单调改善至 K=25 仍未反转（状态匹配收益持续压过样本量损失，边际收益收窄中）。早期"时间归一化不落地"的旧结论是在混合分布测试集上判的——对近期状态口径，分布偏移是主要矛盾。注意：部分收益是尺度对齐（全量模型预测平均状态偏慢）；对绝对 ms 语义的部署当量表，尺度对齐本身就是目的，收益为真；纯排序收益需 scale 校正口径另行量化。**【已落地 2026-08-30（用户决策）】稳定期口径**：不按固定 K 截断，而是边界方法（§5.1）自动确定稳定期（session 总时中位 → 3-session 滚动中位 → R=末 5 平滑值中位 → 自末向前最早连续 ≤R×1.10 的 session），训练/测试/部署模型均在稳定期内；首跑 46.8ms/+0.531 与本实验预测（~48.5）吻合；错误率模型例外仍用全量数据。

**错误率模型结构升级（更大参数是否值得）**：事件量增至 27,862（错误 556）后重检"稀疏约束"。同折 5-fold（seed 0）：逻辑回归 9 特征 0.618 ± 0.006；13 特征 0.621；+键对 one-hot（69 维）0.622 ± 0.023；HistGBM 0.613（反而更差）；键位嵌入 MLP（~1.6k 参数，含前键）0.621 ± 0.002（方差最小）。**最优仅超基线 +0.004，在折内 std 内——更大参数无收益，错误过程的可预测性受特征信息量限制而非模型容量**，维持现行 9/13 特征逻辑回归（分析-错误率规律.py）。

## 7. 应用

- **应用域**：当量仅用于 4 码内的词内评估（主要是 4 码二字词，2/3 码简码同表覆盖）；词间分词间隔自然存在，跨词连续序列不在建模范围（§6.5 结论 3）
- **编码方案评估**：将方案的常用编码代入当量表（当量-2-4键.txt 或期望版），计算平均击键总时间
- **键位优化**：调整个别键位映射后重新计算总当量，评估优化效果（对比用两键累加对照表）
- **键盘布局设计**：评估新布局的运动学效率（注意模型为 QWERTY 30 键采样训练，非 QWERTY 布局需重新采样）

## 8. 复现

### 命令链

```bash
python 当量采集工具.py                   # 1. 采集（可选：已有数据可直接训练）
python 击键模型.py --full               # 2. 测试集评估 + 部署模型(全数据)训练 + 导出段表 npz
python 分析-错误率规律.py               # 3. 错误率模型 → 当量-键对错误率.txt
python 组装当量表.py --expected         # 4. 组装 2-4 键当量表 + 期望表
python 组装当量表.py --baseline         # 5. 两键累加对照表（对比评估用）
python 组装-chai当量表.py --selftest    # 6.（可选）chai 差值表 (t2/t3/t4 校正 gram)
```
