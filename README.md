# 击键测速 — 条件击键当量建模

**条件击键当量**（Conditional Keystroke Equivalent，简称"当量"）：从个人打字测速数据中学习**前键条件下**键位间的击键时间成本（ms，非物理距离），输出段当量母表与 2/3/4 键当量表，用于输入法编码方案评估与键位优化。

**摘要**：传统键位成本模型用 2 键当量逐对累加，假设"打完一个键手就回位"。实测表明该假设系统性低估整串耗时（86.5% 的 trial），且低估幅度按键对类型不均（跨手 +42ms → 同手异指 +80ms）——用其评估编码方案约 20% 的排序会被扭曲。本项目以"前键条件段"为单位建模：每段时间 `S(p,a,b)` 以真实前键 p 为条件，整串成本 = 段之和。在当前数据上（5706 trial），模型总时间 MAE 63.5ms（R² +0.417）、排名精度 Spearman 0.637，优于传统 2 键表（MAE 103.7ms / 排名 0.495）。

---

## 1. 背景与动机

键盘输入的成本建模是编码方案评估与键位优化的基础。传统做法（Carpalx、KLA 类工具）使用**2 键当量表** B(a,b)——键对 (a,b) 的击键时间——逐对累加估算整串耗时：

```
T'(abcd) = B(a,b) + B(b,c) + B(c,d)
```

其隐含假设：**键对间独立，打完一个键后手回到静止起始位置**。这一假设在两个层面失实：

1. **中间键对的前键从不是"空"**：打完 `r` 后手指停在 `r` 位，直接击打 `w` 的起点不是 home 位。Rumelhart & Norman (1982) 的击键时序模型早已指出相邻间隔互为条件（"间隔负相关"），且上一键准备完成后可直接启动下一键（不回位）。
2. **低估幅度按键对类型不均**：前键条件下的中段比空前键首段慢（跨手 +42ms、同手异指 +80ms），差异随类型不同——用统一比例修正不了，排序被结构性扭曲。

**条件击键当量**直接建模 `S(p,a,b)` = "前键为 p 时击打键对 (a,b) 的时间"，整串成本 = 段之和：

```
T(abcd) = S(∅,a,b) + S(a,b,c) + S(b,c,d)
```

2 键表是段模型在空前键（∅）下的特例切片——2/3/4 键当量同源同基准，完全自洽。

## 3. 数据采集

### 3.1 采集协议

`python 4码当量采集工具.py`（tkinter GUI）：显示随机 4 字符编码，录入真实击键时间戳。

| 操作 | 行为 |
|------|------|
| 输入显示的 4 个字符 | 正常打字 |
| 输错（任意键） | 立即变红停止，进入随机延迟 |
| 空格 | 跳过当前组（不记录），进入随机延迟 |
| Esc | 退出 |

**采样策略（多样性加权）**：首键均匀随机，后续键按 `w(b|a) ∝ 1/(n(a,b)+1)` 加权——欠样本键对优先（符号键 `;,./` 零样本时自动补足），键对样本量趋均衡后自动回归均匀随机。每次试次结束（正确/错误/跳过统一）延迟 **300-800ms 随机**再显示下一组，打断固定节律，防止"预期性击键"把键对难度差异压缩平均。

TSV，制表符分隔，UTF-8：

```
code    b_d     c_d     d_d     a_u     b_u     c_u     d_u     error   actual  trial   session
jdez    88.6    284.4   537.8   109.6   171.2   386.6   665.4   0               3       20260724-212631
```

| 字段 | 说明 |
|------|------|
| code | 显示的四字符编码（30 键：26 字母 + `;,./`） |
| b_d, c_d, d_d | 第 2/3/4 键按下时间（ms from 首键按下） |
| a_u, b_u, c_u, d_u | 第 1/2/3/4 键放开时间（ms from 首键按下） |

| trial / session | 试次序号 / 启动时间戳（YYYYMMDD-HHMMSS） |

## 4. 方法

### 4.1 问题定义

给定 4 字符编码 `abcd`，预测击键总时间 T（ms）。训练数据每行记录一个随机 4 字符串的实际击键时间戳。

### 4.2 条件段模型

将序列拆成**三段**，每段独立预测，前键作为条件：

```
每段 t = 双线性交互(e) + MLP(e, φ)   S(p,a,b) ≈ e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b + MLP(68→64→1)
  前键空 = 索引 30（可学习的"静止起始"嵌入）

整串当量统一公式 (n 键序列 k₁k₂...kₙ, k₀ = ∅):
  T_n = Σ_{i=1}^{n-1} S(k_{i-1}, k_i, k_{i+1})    每段条件键 = 前一键, 首段 = 空

  两键  T₂(ab)   = S(∅,a,b)                          ← 1 项
  三键  T₃(abc)  = S(∅,a,b) + S(a,b,c)               ← 2 项
  四键  T₄(abcd) = S(∅,a,b) + S(a,b,c) + S(b,c,d)    ← 3 项
```

### 4.3 为什么前键条件（实测证据）

段间隔按**键对类型 × 前键条件**分解（15406 段，MAD 过滤后）：

| 类型 | 空前（首段） | 有前键（中段） | 差 |
|------|------------|--------------|-----|
| 跨手 | 95ms | 138ms | **+42ms** |
| 同手异指 | 105ms | 185ms | **+80ms** |
| 同键重复 | 153ms | 157ms | +4ms |
| 同指异键 | 202ms | 226ms | +24ms |
| **混合平均** | **111ms** | **164ms** | **+53ms** |

所有类型的方向一致（有前键更慢——手打完上一键不回位），但**幅度按类型不均**（跨手 +42 到同手异指 +80ms）。这正是 2 键表不可修的原因：统一比例放大修不了"同手段被低估得更多"的结构性错位（实证见 §5.2）。

模型视角（段表 S(∅,x,y) vs 平均 S(p,x,y)）：跨手 `fi` +15ms、同手异指 `wv` **+105ms**、同指同列 `az` +59ms、同键 `aa` +28ms——同手连续是前键条件最敏感的类型。

### 4.4 模型结构

输入三元组 `(p, a, b)` 经**共享嵌入**与**交互部分**两条路径汇合后加 MLP 头。两种架构（`--model bi|cp`）仅交互部分不同，验证集误差小者胜出（当前双线性 de20/dh64 为默认）。

```
输入: ids = [p, a, b]（31 索引）, φ(a,b) = [同手, 同指, 同键, 列距, 行距, Fitts, 镜像手指, 跨行同指]
共享: e_p, e_a, e_b = E_key[ids]        E_key ∈ ℝ³¹ˣ²⁰（30 键 + 空前键）
```

**① 双线性 + MLP（默认 `--model bi`）**——两两配对交互：

```
S(p,a,b) = e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b  +  MLP([e_p; e_a; e_b; φ])
```

| 组件 | 形状 | 说明 |
|------|------|------|
| W₁/W₂/W₃ | 3 × (20×20) | 显式二阶交互：前键×首键、首键×次键、前键×次键 |
| E_key | 31×20 | 通用键位嵌入（与 W 共享同一套嵌入） |
| MLP | 68→64→1 (ReLU + RMSNorm) | 非线性残差 |

**② CP 张量分解（备选 `--model cp`）**——三向联合交互：`S = Σ_{r=1}^{32} U(p)_r·V(a)_r·W(b)_r + MLP(...)`。历史：双线性扩容前 CP rank=32 曾最优（66.1/0.402），扩容后验证集 R² 0.395 vs 0.343 被反超，降为备选。

**架构选型结论**（5 seed 验证集口径，详见 4.6）：扩容双线性整体优于 CP（MAE -2.6~-3.7，R² +0.04~+0.08）；继续加大参数（de24/dh96 起）过拟合或方差过大——平衡点 de20/dh64（6365 参数）。

### 4.5 键位嵌入与交互特征

键盘为 **3 行 10 列完整 QWERTY（30 键）**：26 字母 + `; , . /`。每键独立可学习向量 `e_k = E[k]`。组装归一化基准限定字母键对，避免符号键量级差异污染最小值。

键位嵌入本身不含手指归属信息，显式注入 8 个文献特征：

```
φ(a,b) = [same_hand, same_finger, same_key, col_dist, row_dist, fitts,
          mirror_pair, cross_row_same_finger]

same_hand(a,b)  = 1  如果 a 和 b 在同一只手（左手=col 0-4，右手=col 5-9），否则 0
same_finger(a,b)= 1  如果 a 和 b 用同一根手指按下，否则 0
same_key(a,b)   = 1  a==b 同键重复（零幅移动需单独建模, 不适用 Fitts）
col_dist / row_dist  = |列差| / |行差|（İşeri & Ekşioğlu 2015: 列>行>手 重要性）
fitts(a,b)      = log2(1 + √(col² + (2·row)²))   Fitts 对数项, W=键宽, 行距≈2 键宽
mirror_pair(a,b)= 1  异手对称手指（Grudin 1983: 换位错误集中于镜像手指）
cross_row_same_finger(a,b) = 1  同指跨行（keygen: 同指顶↔底行最慢最易错）
```

**消融结论**：逐特征 leave-one-out 全部持平（Δ<0.2ms，seed 方差 ±1ms）——显式特征在嵌入模型上无独立贡献（键位嵌入已隐式捕获几何与手指关系），保留 φ8 因文献可解释性（特征权重可作诊断），非性能收益。

### 4.6 训练

- **目标**：批量 MSE（段级），验证集 20%，早停 patience=60，Adam lr=0.001
- **best-of-N 选优（`--trials`，默认 10）**：同参数训练受随机初始化 + 随机划分影响，验证集段 MAE 波动 ~±2ms（R² ±0.12）。训练 N 次、用**验证集段 MAE** 选最强（选优不能用全数据——含训练集会偏向过拟合）
- **异常剔除（段级 MAD 自适应）**：按段位置（t₁/t₂/t₃）分桶，剔除 `|seg − median| ≥ 3σ`（σ = 1.4826×MAD）。中位数稳健、不做硬性上下限——右偏分布下 MAD 下界恒为 0，天然保护最快常规击键（15-40ms）；上界自动适配各段分布。坏段只丢自己，好段保留（与按段训练的模型天然匹配）
- 段样本：每 trial 3 段（t₁: 空→ab, t₂: a→bc, t₃: b→cd），共享 MLP 头，段间互相增强

### 4.7 设计边界

- ❌ **字母 N-gram 频率**：不引入自然语言熟悉度偏差，纯随机采样
- ❌ **连组模式**：每组独立开始（模拟分词间自然停顿），不建模组间转移
- ❌ **节奏/节拍器**：随机延迟打断节律，按"打对条件下尽可能快"测试
- ❌ **变长编码**：仅测 4 字符编码（2/3 键当量为段表切片组合）

## 5. 结果

### 5.1 模型精度（最新模型，4808 完整 trial）

| 目标 | MAE | R² |
|------|-----|-----|
| 段（S） | 35.3ms | — |
| T₂（两键） | 27.5ms | +0.496 |
| T₃（三键） | 47.7ms | +0.347 |
| T₄（四键总时间） | **63.5ms** | **+0.417** |

段当量分布（段表）：基准（最快速字母键对）66ms、字母中位 103ms；全段表 min 67 / 中位 153 / 均值 163 / max 301ms。

### 5.2 与传统 2 键表对比

传统做法用 2 键当量表逐对累加（假设键对独立、前键无关）。**键位优化用的是相对值**，故分三个口径（4808 trial）：

**① 绝对误差**：

| 方法 | MAE | R² |
|------|-----|-----|
| **条件段模型** | **63.5ms** | **+0.417** |
| 两键累加（传统） | 103.7ms | -0.553 |

**② 比例放大后（scale 修正）**：两键累加整体 ×1.263（过原点 OLS 对齐）后 MAE 103.7→74.6ms、R² +0.185——**相对精度差距 15%**（原始 39% 中 24pp 是整体比例偏差）。两键累加低估真实时间的 trial 占比 86.5%。

**③ 排名精度（决定性口径）**——预测与实测的 Spearman 排序相关：

| 方法 | 排名相关 |
|------|---------|
| **条件段模型** | **0.637** |
| 两键累加 | 0.495 |

条件当量排序精度高 **29%**。两键累加虽整体低估，排名仍有 0.495 的可用度——但约 20% 的码会被排错。

**全码空间统计（30⁴ = 810,000 个 4 码，两种方法各算一遍）**：
- 两方法互相的排序相关 Spearman **0.799**
- 两键累加相对条件当量均值 **-95ms**/码（中位 -91ms），99.9% 的码系统性低估；唯一高估侧（0.1%）为含同键重复的码——同键重复零幅移动，条件模型单独建模后成本更高
- 极端低估例：`rwvz` 两键 292ms vs 条件 615ms（-323ms）——连续同手段在无前键条件下被严重低估（`w→v`、`v→z` 中段各差 +158/+166ms）

### 5.3 错误转当量

一次按键错误的时间成本 = 退格 + 注意力重定位 + 重输 ≈ **固定 500ms**（数据推导 ~455ms：错键段 160-221 + 退格 180 + 重打首键 102），与键对运动难度解耦。评估编码时把"打错"的期望成本计入：

```
期望段当量 = 条件段当量 S(p,a,b) + 500ms × P_err(a,b)
整串期望   = Σ 期望段当量（加性保持）
```

**键对错误率模型**（`分析-错误率规律.py`，9 特征逻辑回归，17032 键对事件 / 323 错误，5-fold AUC 0.620±0.039）：

```
P_err(a,b) = σ(−4.273 + 0.484·同手 − 1.873·同指 + 2.243·同指同列
             + 0.375·无名-中指 − 0.013·小指-无名 + 2.149·同指双列
             + 0.356·b左小指 − 0.420·b顶行 + 0.262·b底行)
```

特征全为键位可计算量（`同手/同指` 手位关系、4 个坏指对、`b左小指` 及目标键行）。原始统计级错误率噪声大（每键对仅 ~15 样本），模型输出受特征结构约束更稳。系数是正确率模型取反——`同指` 负系数因含同键重复（0.2% 低错）拉低，坏子类由坏指对特征单独暴露。

**键对难度参考**（段间隔，15406 段）：跨手 124ms < 同键重复 156ms < 同手异指 159ms < 同指异键 218ms。

## 6. 讨论

### 6.1 局限性

- **串行假设**：段模型假设相邻击键串行。Dhakal et al. (2018) 显示熟练打字员 40-70% 的按键存在 rollover（重叠），重叠 30-100ms——逐段求和可能系统性高估极快打字状态。当前数据为自测（打对条件下尽快），重叠比例未量化
- **误差重尾**：飞行时间近似 log-logistic（重尾），沉思停顿可达数秒；MAD 剔除处理了异常，但纯 MAE 对重尾敏感（可考虑分位数目标）
- **单用户**：模型为个人指法特征（含小指弱势等个体差异），人群外推需 136M Keystrokes 类数据验证

### 6.2 文献特征消融（2026-08-11）

错误率模型侧：镜像手指/跨行同指/相邻手指/方向不对称 4 个文献特征**无增益**（13 特征 AUC 0.619 ≈ 9 特征 0.620）——与现有坏指对高度共线。分层确认：镜像手指在本数据是**保护项**（2.87% < 非镜像 3.86%——Grudin 的换位错误占比 ≠ 键对风险）；b 离拇指侧更易错（5.16% vs 3.87%，Lachnit 方向不对称确认）。双向计数（错键事件并入）AUC 降至 0.600 但错误事件翻倍、校准更稳（`--dual` 开关保留）。

### 6.3 未来工作

- **三元组交互**：Carpalx 的 k1:k2:k3 = 60:30:10 结构提示跨键对涌现惩罚（同手 4 连、反向 roll），现模型逐对求和无法表达
- **人群先验**：136M Keystrokes 数据集（168k 人，公开免费）可作稀疏键对的先验/外部验证
- **rollover 显式建模**：记录并利用 key-up 时间，重叠比例作特征或诊断指标
- **错误率数据积累**：~5-10 万 trial 后可升级 26 类指对嵌入/目标指难度特征（当前类别自由参数全部过拟合）

## 7. 应用

- **编码方案评估**：将方案的常用编码代入当量表（当量-2-4键.txt 或期望版），计算平均击键总时间
- **键位优化**：调整个别键位映射后重新计算总当量，评估优化效果（对比用两键累加对照表）
- **键盘布局设计**：评估新布局的运动学效率（注意模型为 QWERTY 30 键采样训练，非 QWERTY 布局需重新采样）

### 命令链

```bash
python 4码当量采集工具.py                # 1. 采集（可选：已有数据可直接训练）
python 击键模型.py --full               # 2. 训练（best-of-10）+ 导出段表 + 模型
python 分析-错误率规律.py               # 3. 错误率模型 → 当量-键对错误率.txt
python 组装当量表.py --expected         # 4. 组装 2-4 键当量表 + 期望表
python 组装当量表.py --baseline         # 5. 两键累加对照表（对比评估用）
```

### 输出文件

| 文件 | 内容 |
|------|------|
| 当量-段表.txt | 27,900 条 S(p,a,b) 母表（`_`=空前键），其他当量查表组合 |
| 当量-2-4键.txt | 837,900 条 2/3/4 键当量（归一化，基准=最快速字母键对） |
| 当量-期望-2-4键.txt | 期望当量（含 500ms×P_err 错误成本） |
| 当量-两键累加-2-4键.txt | 传统基线对照表（同规格同基准） |
| 当量-键对错误率.txt | 900 键对 P_err |
| keystroke_model.pt | 模型参数（`KeystrokeModel.load()` + `model.total(code)` 预测任意 4 码） |

复现评估：`对比-条件vs两键.py`（本地脚本，含条件 vs 2 键对比与 scale 修正）。

### 目录

```
击键测速/
├── README.md            # 本文件
├── 4码当量采集工具.py      # 数据采集（tkinter GUI）
├── 击键模型.py           # 模型训练 + 评估 + 导出（PyTorch）
├── 分析-错误率规律.py    # 错误数据统计与规律分析
├── 组装当量表.py        # 段表 → 2-4 键当量表组装工具
├── keystroke_model.pt   # 模型参数（随仓库分发）
├── 击键测速数据.tsv      # 采集的原始数据（本地私有，不随仓库分发）
└── 当量-*.txt           # 生成产物（击键模型.py --full / 分析-错误率规律.py / 组装当量表.py）
```
