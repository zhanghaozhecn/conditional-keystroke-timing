# 击键测速 — 条件击键当量建模

**条件击键当量**（Conditional Keystroke Equivalent，简称"当量"）：从打字测速数据中学习**前键条件下**键位间的击键时间成本（ms，非物理距离），输出段当量母表与 2/3/4 键当量表，用于输入法编码方案评估与键位优化。

核心技术：每段时间 `S(p,a,b)` 以前键 p 为条件——中间键对的运动成本受"手从哪里来"影响，整串成本 = 段之和。

## 快速开始

### 环境

- Python 3.10+
- PyTorch（CPU 即可——小模型 GPU 开销反超）
- NumPy
- tkinter（Python 自带）

### 1. 采集数据

```bash
python 4码当量采集工具.py
```

操作说明：

| 操作 | 行为 |
|------|------|
| 输入显示的 4 个字符 | 正常打字 |
| 输错（任意键） | 立即变红停止，进入随机延迟 |
| 空格 | 跳过当前组（不记录），进入随机延迟 |
| Esc | 退出 |

**采样策略（多样性加权）**：首键均匀随机，后续键按 `w(b|a) ∝ 1/(n(a,b)+1)` 加权——欠样本键对优先（符号键 `;,./` 零样本时自动补足），键对样本量趋均衡后自动回归均匀随机。启动时读取已有数据统计键对计数。

每次试次结束（正确/错误/跳过统一）延迟 **300-800ms 随机**再显示下一组——打断固定节律，防止"预期性击键"把键对难度差异压缩平均。

### 2. 训练模型

```bash
python 击键模型.py --model bi   # 默认: 双线性 de20/dh64 (验证集误差最小)
python 击键模型.py --model cp   # 备选: CP 张量分解
python 击键模型.py --trials 20  # 训练 20 次取验证集最优 (默认 10)
python 击键模型.py --full    # 追加导出当量表（段表 + 组装）
python 组装当量表.py          # 段表 → 2-4 键当量表（纯查表，无需模型）
python 组装当量表.py --expected  # 追加期望当量表（计入错误成本，见"错误转当量"）
```

当前实测（5320 trials，双线性 de20/dh64 + RMSNorm + φ8 特征，best-of-N=10）：段 MAE 35.3ms，四键总时间 MAE 63.5ms，R² 0.417（全数据）。

## 模型架构

### 问题定义

给定 4 字符编码 `abcd`，预测击键总时间 `T`（ms）。训练数据每一行记录一个随机 4 字符串的实际击键时间戳。

### 条件段模型

将序列拆成**三段**，每段独立预测，前键作为条件：

```
每段 t = 双线性交互(e) + MLP(e, φ)   S(p,a,b) ≈ e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b + MLP(62→64→1)
  前键空 = 索引 30（可学习的"静止起始"嵌入）

整串当量统一公式 (n 键序列 k₁k₂...kₙ, k₀ = ∅):
  T_n = Σ_{i=1}^{n-1} S(k_{i-1}, k_i, k_{i+1})    每段条件键 = 前一键, 首段 = 空

  两键  T₂(ab)   = S(∅,a,b)                          ← 1 项
  三键  T₃(abc)  = S(∅,a,b) + S(a,b,c)               ← 2 项
  四键  T₄(abcd) = S(∅,a,b) + S(a,b,c) + S(b,c,d)    ← 3 项
```

**为什么前键条件**：本段时间受"手从哪里来"影响（动量/手指位置记忆）——实测中段（有前键）213ms 比首段（空前键）136ms 慢 77ms；中间键对的前键从不是"空"，用"从空开始"的当量会系统性高估速度。整串评估必须用条件组合，传统 2 键表累加会低估整串约 24%（详见"与传统 bigram 累加的对比"）。

### 模型结构

输入三元组 `(p, a, b)`（p = 前键或空前键）经**共享嵌入**与**交互部分**两条路径汇合后加 MLP 头。两种架构（`--model bi|cp`）仅交互部分不同，输入结构、MLP 头、训练目标完全一致，验证集误差小者胜出（当前双线性 de20/dh64 为默认）。

```
输入: ids = [p, a, b]（31 索引）, φ(a,b) = [同手, 同指, 同键, 列距, 行距, Fitts, 镜像手指, 跨行同指]
共享: e_p, e_a, e_b = E_key[ids]        E_key ∈ ℝ³¹ˣ²⁰（30 键 + 空前键）
```

**① 双线性 + MLP 模型（默认 `--model bi`）**——两两配对交互：

```
S(p,a,b) = e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b  +  MLP([e_p; e_a; e_b; φ])
```

| 组件 | 形状 | 说明 |
|------|------|------|
| W₁/W₂/W₃ | 3 × (20×20) | 显式二阶交互：前键×首键、首键×次键、前键×次键 |
| E_key | 31×20 | 通用键位嵌入（与 W 共享同一套嵌入） |
| MLP | 68→64→1 (ReLU + RMSNorm) | 非线性残差：显式交互捕捉二阶规律，MLP 补 φ 特征与高阶非线性；隐藏层后 RMSNorm 微增益（激活扫描 relu 最优，leaky/sigmoid/relu²/silu/swiglu 全灭） |

**② CP 张量分解模型（备选 `--model cp`）**——三向联合交互：

```
S(p,a,b) = Σ_{r=1}^{32} U(p)_r · V(a)_r · W(b)_r  +  MLP([e_p; e_a; e_b; φ])
```

| 组件 | 形状 | 说明 |
|------|------|------|
| U / V / W | 3 × (31×32) | 角色因子嵌入：键作为前键/首键/次键各一套独立表示，点乘出三向联合交互（rank=32，rank 扫描 8→32 提升、48 过拟合回落） |
| E_key | 31×12 | 通用键位嵌入（喂 MLP 头） |
| MLP | 38→24→1 (ReLU) | 非线性残差 |

**对比实测**（5 seed 验证集，4195 trials）：双线性 de20/dh64 验证 MAE 61.7 / R² 0.395 vs CP rank=32 64.3 / R² 0.343（R² 高 15%）→ 双线性反超成为默认。扩容扫描结论：双线性增大参数（de/dh 加大、MLP 加深）先升后降，de24/dh96 起过拟合（65.3）、de48/dh192 三层方差过大（60.8±8.2）——误差最小与过拟合风险的平衡点在 de20/dh64（5917 参数）。**共享 MLP 头**：三段共一套参数，全部段样本参与训练（每 trial 贡献 3 段），段间互相增强。两键当量是段模型在空前键下的特例——2/3/4 键当量同源同基准，完全自洽。

### 键位嵌入

键盘为 **3 行 10 列完整 QWERTY（30 键）**：26 字母 + `; , . /`（支持含符号的编码方案）。每键独立可学习向量：

```
e_k = E[k]        E ∈ ℝ³¹ˣ²⁰  (30 键 + 空前键; CP 备选为 12 维)
```

符号键（`;,./`）无历史样本时嵌入不更新（当量暂时不准），随采集精化；组装归一化基准限定字母键对，避免随机嵌入污染。

### 交互特征

键位嵌入本身不含手指归属信息，显式注入 8 个文献特征（2026-08-11；逐特征消融 LOO 全部持平 Δ<0.2ms——显式特征在嵌入模型上无独立贡献，保留 φ8 因文献可解释性，非性能）：

```
φ(a,b) = [same_hand, same_finger, same_key, col_dist, row_dist, fitts,
          mirror_pair, cross_row_same_finger]

same_hand(a,b)  = 1  如果 a 和 b 在同一只手（左手=col 0-4，右手=col 5-9），否则 0
same_finger(a,b)= 1  如果 a 和 b 用同一根手指按下，否则 0
same_key(a,b)   = 1  a==b 同键重复（文献: 零幅移动需单独建模, 不适用 Fitts）
col_dist / row_dist  = |列差| / |行差|（İşeri & Ekşioğlu 2015: 列>行>手 重要性）
fitts(a,b)      = log2(1 + √(col² + (2·row)²))   Fitts 对数项, W=键宽, 行距≈2 键宽
mirror_pair(a,b)= 1  异手对称手指（Grudin 1983: 换位错误集中于镜像手指）
cross_row_same_finger(a,b) = 1  同指跨行（keygen: 同指顶↔底行最慢最易错）
```

### 训练

- 批量 MSE（段级目标），验证集 20%，早停 patience=60，Adam lr=0.001
- **best-of-N 选优（`--trials`，默认 10）**：同参数训练受随机初始化 + 随机划分影响，验证集段 MAE 波动 ~±2ms（R² ±0.12）。每次训练秒级，故训练 N 次、用**验证集段 MAE** 选最强（选优不能用全数据——含训练集，会偏向过拟合模型）。实测 10 次最优验证段 MAE 39.6ms vs 单次均值 ~41ms
- **异常剔除（段级 MAD 自适应）**：按段位置（t₁/t₂/t₃）分桶，剔除 `|seg − median| ≥ 3σ`（σ = 1.4826×MAD）的段。中位数稳健、不做硬性上下限——右偏分布下 MAD 下界恒为 0，天然保护最快常规击键（实测 15-40ms）；上界自动适配各段分布。坏段只丢自己，好段保留（与按段训练的模型天然匹配）
- 段样本：每 trial 3 段（t₁: 空→ab, t₂: a→bc, t₃: b→cd）

### 设计边界

- ❌ **字母 N-gram 频率**：不引入自然语言熟悉度偏差，纯随机采样
- ❌ **连组模式**：每组独立开始（模拟分词间自然停顿），不建模组间转移
- ❌ **节奏/节拍器**：随机延迟打断节律，按"打对条件下尽可能快"测试
- ❌ **变长编码**：仅测 4 字符编码

## 数据格式

### 输入（测速工具产出）

TSV，制表符分隔，UTF-8：

```
code    b_d     c_d     d_d     a_u     b_u     c_u     d_u     error   actual  trial   session
jdez    88.6    284.4   537.8   109.6   171.2   386.6   665.4   0               3       20260724-212631
```

| 字段 | 说明 |
|------|------|
| code | 显示的四字符编码 |
| b_d, c_d, d_d | 第 2/3/4 键按下时间（ms from 首键按下） |
| a_u, b_u, c_u, d_u | 第 1/2/3/4 键放开时间（ms from 首键按下） |
| error | 0=正确, 1=错误 |
| actual | 错误时记录的实际按键（正确时为空） |
| trial | session 内试次序号（1-based） |
| session | 启动时间戳（YYYYMMDD-HHMMSS） |

### 输出

**当量-段表.txt**（31×30×30 = 27,900 条）：条件击键当量**母表** `S(p,a,b)`——前键 p 条件下击打键对 (a,b) 的时间（ms 原始值，未归一化）。`_` 表示空前键。格式：`p\ta\tb\tms`（TSV，3 行注释头）。这是 S 函数的完整定义域映射，其余当量全部由后续模块查表组合（避免冗余存储）：

```
T_n(k₁..kₙ) = Σ S[k_{i-1}, k_i, k_{i+1}]   (k₀ = _ 空前键; 每段条件键 = 前一键)
T₂ = S[_,a,b];  T₃ = S[_,a,b]+S[a,b,c];  T₄ = S[_,a,b]+S[a,b,c]+S[b,c,d]
任意前缀续打: 已打 p, 续打 xyz = S[p,x,y] + S[x,y,z]
```

归一化按需：除以最快速**字母**键对（实测 ~63ms）即得当量比值。

**当量-2-4键.txt**：`组装当量表.py` 从段表组装（纯查表+相加，无需模型）：2 键区（aa-//，900 条）→ 3 键区（aaa-///，27,000 条）→ 4 键区（aaaa-////，810,000 条），共 837,900 条，格式 `code\t当量`，归一化基准 = 最快速**字母**键对。**4 码方案键位优化的直接查表依据**。

**当量-键对错误率.txt**：`分析-错误率规律.py` 导出，900 键对直接 P_err（格式 `pair	err_rate`），供期望当量查表。

**当量-期望-2-4键.txt**：`组装当量表.py --expected` 从段表 + 错误率表组装（837,900 条，格式同 当量-2-4键.txt），期望当量 = 条件段当量 + 500ms×P_err——评估时计入打错成本（见"错误转当量"）。

**keystroke_model.pt**：模型参数，可通过 `KeystrokeModel.load(path)` 加载后调用 `model.total(code)` 预测任意 4 字符编码的击键总时间。

## 应用场景

- **编码方案评估**：将方案的常用编码代入模型/当量表，计算平均击键总时间
- **键位优化**：调整个别键位映射后重新计算总当量，评估优化效果
- **键盘布局设计**：评估新布局的运动学效率

## 与传统 bigram 累加的对比

传统做法（2 键当量表逐对累加）假设键对间独立、前键不影响成本。实测差距（4808 完整 trial，φ8 模型，2026-08-11）。**键位优化用的是相对值**，故分三个口径：

**① 绝对误差（原始口径）**：

| 方法 | 总 MAE | 总 R² |
|------|--------|-------|
| **条件段模型** | **63.5ms** | **+0.417** |
| 两键累加（传统） | 103.7ms | **-0.553** |

**② 比例放大后（scale 修正，键位优化的公平口径）**：两键累加整体按 k=1.263 对齐（过原点 OLS）后，MAE 103.7→**74.6ms**、R² -0.553→+0.185——**相对精度差距 15%**（原始 39% 中 24pp 是整体比例偏差）。

**③ 排名精度（决定性口径）**：预测与实测的 Spearman 排序相关——

| 方法 | 排名相关 |
|------|---------|
| **条件段模型** | **0.637** |
| 两键累加 | 0.495 |

条件当量排序精度高 **29%**；两键累加虽整体低估 86.5% 的 trial，排名仍有 0.495 的可用度——但评估编码优劣时 20% 的码会被排错。

**④ 第三方模型对照（键魂当量，2313 交集码，码级均值口径）**：

| 方法 | MAE | R² | scale 后 MAE | scale 后 R² | 排名 |
|------|-----|-----|------------|-----------|------|
| **条件段模型** | 92.3ms | +0.160 | **88.7ms** | **+0.342** | **0.629** |
| 两键累加 | 169.5ms | -0.992 | 102.7ms | +0.164 | 0.460 |
| 键魂 | 124.8ms | -0.169 | 125.1ms | -0.167 | 0.425 |

键魂尺度几乎已对齐（k=1.010 无需放大），但其偏差是**结构性**的——scale 修正后 R² 仍为负；排名 0.425 与两键累加（0.460）同档，明显低于条件当量（+48%）。方法互比：键魂与两键排名相关 0.655 > 与条件 0.642——键魂行为接近"无前键条件"模型。

**全码空间统计（30⁴ = 810,000 个 4 码，两种方法各算一遍）**：
- 两方法互相的排序相关 Spearman **0.799**——用两键表评估编码方案，约 20% 的排序会被扭曲
- 两键累加相对条件当量均值 **-95ms**/码（中位 -91ms），99.9% 的码系统性低估；唯一高估侧（0.1%）为含同键重复的码——同键重复零幅移动，条件模型单独建模后成本更高
- 极端低估例：`rwvz` 两键 292ms vs 条件 615ms（-323ms）——连续同手/同指段在无前键条件下被严重低估（`w→v`、`v→z` 中段各差 +158/+166ms）

**生成对照表**：`组装当量表.py --baseline` 输出 当量-两键累加-2-4键.txt（837,900 条，与主表同规格同基准），可直接与 当量-2-4键.txt 逐码对比。复现评估：`对比-条件vs两键.py`（本地脚本）。

## 错误转当量

一次按键错误的时间成本 = 退格 + 注意力重定位 + 重输 ≈ **固定 500ms**（数据推导 ~455ms：错键段 160-221 + 退格 180 + 重打首键 102，位置相关差异小），与键对运动难度解耦。评估编码时把"打错"的期望成本计入：

```
期望段当量 = 条件段当量 S(p,a,b) + 500ms × P_err(a,b)
整串期望   = Σ 期望段当量（加性保持）
```

**键对错误率模型**（`分析-错误率规律.py`，9 特征逻辑回归，实测 17032 键对事件 / 323 错误，5-fold AUC 0.620±0.039）：

```
P_err(a,b) = σ(−4.273 + 0.484·同手 − 1.873·同指 + 2.243·同指同列
             + 0.375·无名-中指 − 0.013·小指-无名 + 2.149·同指双列
             + 0.356·b左小指 − 0.420·b顶行 + 0.262·b底行)
```

特征全为键位可计算量：`同手/同指` 手位关系，4 个坏指对（同指同列、无名-中指、小指-无名、同指双列），`b左小指` 及目标键行（顶/底行）。原始统计级错误率噪声大（每键对仅 ~15 样本），模型输出受特征结构约束更稳。注意系数是正确率模型（正值=更正确）取反——`同指` 负系数因含同键重复（0.2% 低错）拉低，坏子类由坏指对特征单独暴露。

使用流程：

```bash
python 分析-错误率规律.py                # → 当量-键对错误率.txt（900 键对）
python 组装当量表.py --expected          # → 当量-期望-2-4键.txt（837,900 条）
```

归一化基准与 当量-2-4键.txt 同为最快速字母键对，两条评估口径（纯速度 / 含错误期望）可直接对比。

**数据现状**：错误事件尚少（数百级），类别自由参数（18 类手位置 / 26 类指对 one-hot 等）全部过拟合（AUC 0.53-0.59 < 特征 LR 0.62）——线性压缩特征在数据量下最优；数据积累到 ~5-10 万 trial 后可升级 26 类指对嵌入/目标指难度特征。

**文献特征验证（2026-08-11）**：镜像手指/跨行同指/相邻手指/方向不对称 4 个文献特征经消融**无增益**（13 特征 AUC 0.619 ≈ 9 特征 0.620）——与现有坏指对高度共线；分层确认镜像手指在本数据是**保护项**（2.87% < 非镜像 3.86%，Grudin 换位占比 ≠ 键对风险）、b 离拇指侧更易错（5.16% vs 3.87%）。双向计数（错键事件并入）AUC 降至 0.600（错键语义弱化）但错误事件翻倍、校准更稳（`--dual` 开关保留）。
