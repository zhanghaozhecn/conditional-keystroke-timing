# 击键测速 — 条件击键当量建模

**条件击键当量**（Conditional Keystroke Equivalent，简称"当量"）：从个人打字测速数据中学习**前后键条件下**键位间的击键时间成本（ms，非物理距离），输出段当量母表与 2/3/4 键当量表（错误期望成本内含），用于输入法编码方案评估与键位优化。

**摘要**：传统键位成本模型用 2 键当量逐对累加，假设"打完一个键手就回位"。实测表明该假设系统性低估整串耗时，且低估幅度按键对类型不均（跨手 +42ms → 同手异指 +80ms，§5.4）——用其评估编码方案约 20% 的排序会被扭曲。本项目以"对称条件段"为单位建模：每段时间 `S(p,a,b,n)` 同时以前两键与**后继键**为条件，整串成本 = 段之和；错误期望成本按段签名计入，"当量"的完整定义 = 运动成本 + 错误成本（§4.6-§4.7）。固定 trial 测试集上总时间 MAE 38.5ms（R² +0.643）、排名精度 Spearman 0.809，4 码/2 键两项分别领先陈一凡 1986 群体两键表 31%/51%（§5.3）；模型已贴实测噪声下界（§5.2）。

## 1. 引言

键盘输入的时间成本模型是输入法编码方案评估与键位优化的基础。传统工具（Carpalx、KLA 类）以 **2 键当量表** B(a,b)——键对 (a,b) 的击键时间——逐对累加估算整串耗时：

```
T'(abcd) = B(a,b) + B(b,c) + B(c,d)
```

其隐含假设：键对间独立，打完一个键后手回静止起始位。该假设在两个层面失实：

1. **串中键对的前键从不是"空"**：打完 `r` 后手指停在 `r` 位，击打 `w` 的起点不是 home 位——相邻间隔互为条件、上一键准备完成后可直接启动下一键（Rumelhart & Norman 1982 的"间隔负相关"与"不回位"）。
2. **低估幅度按键对类型不均**：有前键的中段比空前键首段慢（跨手 +42ms、同手异指 +80ms，§5.4）——统一比例修正处理不了"同手段被低估更多"的结构性错位，编码方案排序被扭曲（约 20% 排序翻转）。

本项目以**对称条件段**为单位直接建模：段 `S(p,a,b,n)` = "前两键为 p,a 时击打键对 (a,b) 的时间（含后继键 n 的准备成本）"，整串成本 = 段之和：

```
T(abcd) = S(∅,a,b,c) + S(a,b,c,d) + S(b,c,d,∅)
```

2 键表是段模型在空前键（∅）+ 无后继（∅）下的特例切片——2/3/4 键当量同源同尺度，完全自洽。

主要结果与贡献：

- **对称条件段模型**：前键条件效应 +42~80ms 且按键对类型不均（§5.4）、后键条件增益 −1.3~−1.6ms 两组独立批次复现——单一段表示统一 2/3/4 键当量
- **个人稳定期数据全链路**：2/4 键混采协议（欠样本加权、随机延迟去节律）、稳定期边界方法（自动剔练习漂移，§5.1）、B4b 两阶段残差异常剔除（§4.5）
- **部署混合模型 v3.1**（XGB + 神经分量 ×5 固定种子平均，无选优噪声）：固定 trial 测试集总时间 MAE 38.5ms / R² +0.643 / 4 码排名 Spearman 0.809（§5.2），4 码/2 码两项分别领先陈一凡 1986 群体两键表 31%/51%（§5.3）
- **签名条件错误率模型与修正段当量**：错误期望成本（实测错误成本 × P_err，随采集动态更新）按段签名计入，"当量"完整定义 = 运动成本 + 错误成本（§4.6-§4.7）
- **样本量终局**：模型已贴实测噪声底（段固有噪声 σ≈33.3ms），专项扩容零收益（§5.2）

## 3. 数据

### 3.1 采集协议

`python 当量采集工具.py`（tkinter GUI）：显示随机编码，录入真实击键时间戳。

**2/4 键混采**：每试次以 P2=0.30 概率出 **2 键码**（其余 4 键）。2 键试次服务对称段模型的 T₂ 角点 S(∅,a,b,∅) 测量——4 键试次的首段总带真后键，该"词首+词末"组合只能靠 2 键试次直接测量。2 键与 4 键各用**独立的欠样本键对池**：4 键池喂段覆盖，2 键池喂 900 键对的角点覆盖；2 键行 code 长度 2、c_d/d_d=0 填充，下游按 `len(code)==4` 过滤。

| 操作 | 行为 |
|------|------|
| 输入显示的 2/4 个字符 | 正常打字 |
| 输错（任意键） | 立即变红停止，进入随机延迟 |
| 空格 | 跳过当前组（不记录），进入随机延迟 |
| Esc | 退出 |

**采样策略（多样性加权）**：首键均匀随机，后续键按 `w(b|a) ∝ 1/(n(a,b)+1)` 加权——欠样本键对优先（符号键 `;,./` 零样本时自动补足），键对样本量趋均衡后自动回归均匀随机。每次试次结束（正确/错误/跳过统一）延迟 **300-800ms 随机**再显示下一组，打断固定节律，防止"预期性击键"把键对难度差异压缩平均。

TSV，制表符分隔，UTF-8：

```
code    b_d     c_d     d_d     a_u     b_u     c_u     d_u     error   actual  trial   session
jdez    88.6    284.4   537.8   109.6   171.2   386.6   665.4   0               3       20260724-212631
```

| 字段 | 说明 |
|------|------|
| code | 显示的编码（30 键：26 字母 + `;,./`；4 键为主，混入 2 键行 c_d/d_d=0） |
| b_d, c_d, d_d | 第 2/3/4 键按下时间（ms from 首键按下） |

**释时字段语义**：模型训练与当量表只用按下时间（b_d/c_d/d_d），释时（*_u）仅供 rollover 诊断。历史上两处释时缺陷已修复（同键连击释时错配、末键释时偶发缺失），受影响历史行的释时按"无有效释时=0"约定置 0、不回填；释时全>0 的行才是无偏诊断口径。

## 4. 方法

### 4.1 问题定义

给定 4 字符编码 `abcd`，预测击键总时间 T（ms）。训练数据每行记录一个随机 4 字符串的实际击键时间戳。

### 4.2 对称条件段模型（v3 混合部署）

将序列拆成**三段**，每段独立预测，**前两键 + 后继键**共同条件（对称段模型 `S(p,a,b,n)`）：

```
每段 t = 双线性交互(e) + MLP(e, φ15)   S(p,a,b,n) ≈ e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b + MLP(75→128→64→1 + Dropout0.2)
  前键空/无后继 = 索引 30（∅）
  φ15 = φ8(a,b) 几何 + φsuc7 后键特征 [存在, 同手(b,n), 同指(b,n), 同键(b,n), Fitts(b,n), 同手(a,n), Fitts(a,n)]
  n=∅ 时 φsuc 全 0 (存在位=0); n 仅经特征进入 (几何身份≈嵌入身份, 5 双线性无增益)

部署混合 (BlendModel): S̄ = 0.3×XGBRegressor(独热124+φ15) + 0.7×mean_{s∈{0..4}} S_deep2(s)
  无选优环节 → 无选优抽签噪声 (决策带从 ±3 缩至仅测试重洗 ~±1ms), 同数据逐位确定

整串当量统一公式 (n 键序列 k₁k₂...kₙ, k₀ = k_{n+1} = ∅):
  T_n = Σ_{i=1}^{n-1} S(k_{i-1}, k_i, k_{i+1}, k_{i+2})    首段前键=∅, 末段后键=∅

  两键  T₂(ab)   = S(∅,a,b,∅)                                        ← 1 项 (角点, 2 键试次直接测量)
  三键  T₃(abc)  = S(∅,a,b,c) + S(a,b,c,∅)                           ← 2 项
  四键  T₄(abcd) = S(∅,a,b,c) + S(a,b,c,d) + S(b,c,d,∅)              ← 3 项
```

### 4.3 模型结构

输入四元组 `(p, a, b, n)` 中三键 `(p,a,b)` 经**共享嵌入**与**交互部分**两条路径汇合后加 MLP 头，后键 `n` 经 φsuc7 特征进入 MLP（sym_phi 形式）。部署为混合（XGB 分量 + 神经分量×5 平均）。

```
输入: ids = [p, a, b, n]（31 索引, n 仅经 φ 生效）, φ15 = φ8(a,b) + φsuc7(b/a, n)
共享: e_p, e_a, e_b = E_key[ids[:, :3]]   E_key ∈ ℝ³¹ˣ²⁰（30 键 + ∅）
```

**① 神经分量（deep2 v3.1，19,997 参数）**——两两配对交互 + 深化 MLP：

```
S(p,a,b,n) = e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b  +  MLP([e_p; e_a; e_b; φ15])
```

| 组件 | 形状 | 说明 |
|------|------|------|
| W₁/W₂/W₃ | 3 × (20×20) | 显式二阶交互：前键×首键、首键×次键、前键×次键 |
| E_key | 31×20 | 通用键位嵌入（与 W 共享同一套嵌入） |
| MLP | 75→128→64→1 (ReLU+RMSNorm+Dropout0.2) | 非线性残差（含 φsuc 后键特征）；dropout 使集成成员去相关、放大预测平均收益 |

**② XGB 分量（确定性）**——XGBRegressor（500 树 / lr 0.06 / depth 6 / subsample 0.8 / colsample 0.8），设计矩阵 = 独热(p,a,b,n 各 31) 124 维 + φ15 = 139 维；种子稳定 ±0.18ms；自适应部分模式匹配（叶子 = 部分键模式 + φ 区间），对零样本组合外推同样有效（见过/未见三元组分组验证优势均匀）。

**③ 混合**：S̄ = 0.3×S_xgb + 0.7×mean(S_deep2, seeds 0-4)。

### 4.4 键位嵌入与几何特征

键盘为 **3 行 10 列完整 QWERTY（30 键）**：26 字母 + `; , . /`。每键独立可学习向量 `e_k = E[k]`。当量定义：**期望键对耗时，单位 ms**（模型预测原始值，不做相对归一化）。

键位嵌入本身不含手指归属信息，显式注入 8 个文献特征：

```
φ(a,b) = [same_hand, same_finger, same_key, col_dist, row_dist, fitts,
          mirror_pair, cross_row_same_finger]

same_hand(a,b)  = 1  如果 a 和 b 在同一只手（左手=col 0-4，右手=col 5-9），否则 0
same_finger(a,b)= 1  如果 a 和 b 用同一根手指按下，否则 0
same_key(a,b)   = 1  a==b 同键重复（零幅移动需单独建模, 不适用 Fitts）
col_dist / row_dist  = |列差| / |行差|（İşeri & Ekşioğlu 2015: 列>行>手 重要性）
fitts(a,b)      = log2(1 + √(col² + (2·row)²))   Fitts 对数项, W=键宽, 行距≈2 键宽
mirror_pair(a,b)= 1  异手对称手指（Grudin 1983: 换位错误集中于镜像手指）
cross_row_same_finger(a,b) = 1  同指跨行（keygen: 同指顶↔底行最慢最易错）
```

**消融结论**：逐特征 leave-one-out 全部持平（特征互为冗余），但整体删除损失 +1.7ms——φ 作为整体提供嵌入补不上的几何先验，价值在稀疏三元组外推（2/3 段表条目零样本）。手工指对类别编码（独热）与键嵌入+双线性等价（嵌入本身即更细的键对类别表示）；生理学导向改造（指距替代列距等）经两轮独立批实验全部关闭，φ8 维持。

### 4.5 训练协议

- **目标**：批量 MSE（段级），验证集 20%，早停 patience=60，Adam lr=0.001
- **训练形态（无选优）**：固定种子 0-4 训练 5 个神经分量取**预测平均**，与确定性 XGB 混合部署——同数据逐位可复现。选优环节（best-of-N）曾引入 ±2ms 抽签噪声（验证最优候选可为测试最差），已移除
- **可复现性与并行**：模块导入即固定运行环境（单线程+播种）；训练成员构造显式种子化 → 每成员 = (seed, 数据) 纯函数，全流程 25 次训练经 spawn Pool 并行（多核 `--full` 约 4 分钟），`KJ_SEQ=1` 强制串行；并行/串行产物逐位一致
- **验证集泄漏**：同一 trial 的三段共享个人速度因子（trial ICC 0.308），段级随机划分使验证集系统性乐观 ~9ms——**模型对比与报告口径必须用 trial 级留出**（§5.1）
- **异常剔除（B4b 两阶段残差，键对分桶）**：
  1. 段位置分桶 MAD k=3 剔除 → 训练 M0（干净模型提供"期望行为"）
  2. M0 推全数据 → 带符号残差 `y−ŷ`（正 = 比预期慢）
  3. 残差按**键对 (a,b) 分桶**、**单侧上围栏**（r ≥ med + 3·1.4826·MAD）剔除——只删"比该键对合理预期慢"的段（注意力中断只拖慢不加快；偏快是 rollover/预备连击的真实行为不删）。剔除率 ~4.8%（van Selst & Jolicoeur 1994 调研范围 5-10% 内）
  - 依据：全局残差法会把"模型学不会的难键对"的真实慢段当异常删（用模型偏见定义正常，循环论证）；键对分桶修复当量失真。剔除收益在**当量稳健性**而非预测精度（无剔除与 B4b 的测试 MAE 在噪声内）
- 段样本：每 trial 3 段（t₁: 空→ab, t₂: a→bc, t₃: b→cd），共享 MLP 头，段间互相增强

### 4.6 键对错误率模型与错误成本实测

一次按键错误的时间成本与键对运动难度解耦——错误成本按段自身键对、按段签名条件计入（实证 §5.5）。两个数据源：

**① 错误率 P_err（`分析-错误率规律.py`，全量数据）**：

```
P_err(a,b | 有无前键, 有无后键) = σ(w·feat(a,b) + α·有前键 + β·有后键 + γ·前×后)
当前拟合（34226 键对事件 / 682 错误，1.99%）:  α=+1.89   β=+0.70   γ=−1.09 (LRT p=0.004)
类均值: 角点 0.49% / 首段 0.98% / 中段 2.16% / 尾段 3.13%  (四类聚合校准 O/E = 1.00)
```

签名与 S(p,a,b,n) 的 (p,n) 语义统一。特征为键位可计算量（同手/同指/坏指对类/目标行等，9 vs 13 特征集按 5-fold AUC 自动选型）；原始键对统计噪声大（平均 ~38 事件/键对）故用特征结构约束，键对级残差不可辨识。**事件口径**：错误 trial 在错键截断——错键对只记 err、其前的键对记 ok、首键即错不记事件（键对未尝试）。

**② 错误成本 cost（`采集-错误成本.py` + `分析-错误成本.py`）**：连续长随机串（120-200 字母）+ 自然回退纠错，单框逐字符着色（白=未打/绿=对/红=错）——错误发现以立即型为主，对应短码语境。测量"**首错按下 → 首错位置打对**"的净耗时（反事实世界尾段同节奏平移，原始区间即净成本）；连锁错（含同位二次错）吸收为单事件——错误只计首错、时长只记首错间隔；episode 判定在采集端实时完成，只落盘错误键事件与串汇总（`数据/错误成本-错误键.tsv`）。

**时长异常剔除（分析端）**：过程分桶（发现型 imm × 退格数档）桶内单侧 med+3×1.4826×MAD 围栏——语义同 S 模型剔除（注意力中断只拖慢不加快，只删过大侧）；退格/盲打是时长的过程簿记结构（+~400ms/退格、+~350ms/盲打字母）**必须分桶**，否则误删合法的连锁/盲打长纠正；桶 n<8 不设栏（保守）；剔除只作用于时长统计，事件计数与率仍用全部闭合 episode。

**当前实测**（282 事件 / 22959 按键 / 12 有效坐姿，弃首坐姿+围栏剔 4 后 n=278）：全体 782ms（SE 15）/ 立即发现 701ms（n=212）/ 延迟发现 1042ms（n=66）。双成分结构：延迟 = 立即 + 过程增量（回归截距与立即均值差 +4ms 定量成立）。

**定案机制**：续采监控，三判据全满足即冻结 cost——①簇稳健 SE≤30ms（均值位置钉住，T₄ 传导 <±2ms）②近 10 坐姿斜率不显著（近端窗口）③近 5 坐姿均值与全体差 <40ms；监控规则：单次刷新均值变动 >±75ms（2×簇SE）回查。cost 为乘法标量，对优化排名零影响、只定绝对刻度。导出 `产物/错误成本-实测值.txt`（label 行式：cost_ms 数据行 + 手别诊断行——左/右手目标纠错差 +69ms（t=4.1，同手纠错串惩罚，退格位依赖的布局结构），为当量表通用性不入表）。

### 4.7 修正段当量与产物链

错误成本与运动成本合并，构成本项目标准产物链（`组装当量表.py`）：

```
修正段当量 C(p,a,b,n) = 段当量 S(p,a,b,n) + cost × P_err(a,b|段签名)  → 当量-修正段表.npz
  cost = 错误成本实测标量 (产物/错误成本-实测值.txt, 分析-错误成本.py 导出, 随采集动态更新)
2-4 键当量 = 修正段求和:                                            → 当量-2-4键.txt
  T₂(ab)   = C(∅,a,b,∅)                    T₃(abc)  = C(∅,a,b,c) + C(a,b,c,∅)
  T₄(abcd) = C(∅,a,b,c) + C(a,b,c,d) + C(b,c,d,∅)
```

即**本项目"当量"的完整定义包含错误期望成本**（原始段表与错误率表作为两个源表一并保留）。

### 4.8 设计边界

- ❌ **字母 N-gram 频率**：不引入自然语言熟悉度偏差，纯随机采样
- ❌ **连组模式**：每组独立开始（模拟分词间自然停顿），不建模组间转移
- ❌ **节奏/节拍器**：随机延迟打断节律，按"打对条件下尽可能快"测试
- ❌ **变长编码**：仅测 2/4 字符编码（3 键当量为段表切片组合）
- 🎯 **应用域 = 4 码内**：当量的优化与使用仅限 4 码内词内评估（主要 4 码二字词，词间自然分词间隔）——孤立 4 键试次的范式与真实词内输入结构一致；跨词连续序列不在建模范围

## 5. 结果

### 5.1 评估口径

**统一口径：稳定期内固定 trial 测试集**。`stable_pools`（击键模型.py）边界方法（序号块口径）：正确 4 键 trial 按时间序切等大块（150 trial/块）→ 每块总时中位 → 3-块滚动中位平滑 → R = 末 5 块平滑值中位 → 自末向前最早连续满足 平滑值 ≤ R×1.10 的块起（确定性无随机）；2 键 trial 不参与边界计算，按时间序自稳定起点同截归属。稳定期内 seed 2024、20% trial 留出，训练/评估只作用于训练侧，测试集独立 B4b（内部自训 M0，与训练无信息交换）。`python 击键模型.py` 直接输出（确定性流，重跑必得同值）。**部署模型同用稳定期全量**（当量表 = 当前状态语义）。**例外：错误率模型（分析-错误率规律.py）仍用全部数据**（用户决策不随练习过滤——切稳定期会把错误事件砍到 ~40%、系数方差放大约 1.5 倍，而错误率的练习效应仅 +0.4pp/6 周，折算 <2ms/段在噪声下）。

当前快照：稳定期 = 序号块[38]（全局 ok 行 #5701/11952）起、4 键 4647 + 2 键 1605 trial（R=347ms）；测试集 929 + 角点 321。

**跨快照噪声带**：无选优环节 → 无选优抽签噪声；剩余波动仅测试集重洗（数据增长 → N 变 → seed 2024 permutation 重抽，~±1ms）。跨快照的"旧模型×新测试"对比不可用（训练池与对方测试集 ~80% 重叠 = 泄漏）。

**为什么用保留口径（B4b 剔除后）**：

1. **用途匹配**：当量表服务于编码方案评估与键位优化（相对排序）。被剔段是注意力中断，与键对难度无关、对候选编码近似同分布的加性噪声——计入指标只稀释难度信号，不提供方案设计信息
2. **训练分布一致**：段表在 B4b 保留段上训练，保留口径测试集与之同分布
3. **非运动成本已独立建模**：错误成本由 §4.6 显式承担；中断率属会话/状态变量，不是键位属性

全口径定位：**真实场景下界**——若要预测含走神的绝对打字时间，需另建中断率模型；两口径之差即中断段（测试 ~5%）的不可预测性代价。

> 误差必须用模型未见过的数据计算；段级验证泄漏（trial ICC 0.308）使段级验证乐观（§4.5），固定 trial 测试集才是干净口径。评估编码方案用保留口径的**相对排序**（排序不随口径变化），绝对 ms 数以本表为准。

### 5.2 主精度（B4b 剔除，固定 trial 测试集）

| 口径 | 段 MAE | T₄ 总 MAE | R² |
|------|--------|-----------|-----|
| **保留口径**（测试集独立 B4b 后——**本研究唯一默认指标**，理由见 §5.1） | 24.7ms | **38.5ms** | **+0.643** |
| **角点指标**（T₂ 留出 2 键 trial，非循环） | **16.0ms** | 偏差 **−0.6ms** | — |

段当量分布（部署段表 npz，稳定期全量训练）：T₂ 角点中位 63ms（min 43）；词首段（真后键）min 39 / 中位 74 / max 262ms。

**精度天花板**：同上下文重复试次实测组内噪声——角点 σ≈16.7ms（单次 MAE 底 13.3）、段 σ≈33.3ms（段底 26.6、4 键总时底 ~46）——模型现状全部贴底；误差与键对覆盖度无关（分桶平坦，ρ≈0），**定向补任何键对/键型都无精度收益**；学习曲线最后翻倍仅 ~3ms 且已平坦。数据积累的实际收益只剩测试带宽收窄（~±1ms）与稳定期边界更新，维持 P2=0.3 自然积累、每 ~10 session 重跑全链路即可。

### 5.3 与陈一凡表对比

当前模型 vs 陈一凡 1986 表（46 键两键当量表、极速赛码器、30 键交集；`数据/陈一凡当量表.txt`，定位 = 他人群体大数据参照），分两项，陈表在两项中**各自独立比例缩放**。**对比内嵌主流程**：`击键模型.py --full` 在角点指标后自动输出本节两项（评估模型 in-memory，与 §5.2 主指标严格同一模型）。

**[1] 4 码累加**（保留口径，n=929 trial）：

| 方法 | ×k₄ | scale 后 MAE | scale 后 R² | 排名 Spearman |
|------|-----|-------------|------------|--------------|
| **条件段模型（T₄ = 三段和）** | **1.014** | **38.8ms** | **+0.646** | **0.809** |
| 陈一凡累加（逐对求和） | 86.1 | 56.5ms | +0.345 | 0.572 |

**[2] 2 码角点**（2 键留出 trial 逐键对单侧 MAD 清洗后，n=321，非循环）：

| 方法 | 标定 | MAE | 中位 | 排名 Spearman |
|------|------|-----|------|--------------|
| **条件段模型（角点 S(∅,a,b,∅)）** | 本征 ms | **16.0ms** | 13.8 | **0.658** |
| 陈一凡表 | ×k₂=60.0 | 32.4ms | 23.8 | 0.571 |

结论：

1. **4 码：条件模型领先 ~31% MAE、排名 0.809 vs 0.572**，绝对标定近完美（×k₄=1.014 vs 陈表需 ×86 对齐个人速度）
2. **2 码：个人角点 16.0ms 大胜陈表 32.4ms（领先 51%）**——键对级难度由个体差异主导，个人小样本胜过群体大数据
3. **陈表两项缩放系数不同**（×k₄=86.1 vs ×k₂=60.0）——群体表与本人在 2/4 键语境的尺度结构不一致，印证不同被试的绝对当量水平与难度结构均不可迁移（这正是"条件段模型"存在的理由）

### 5.4 前键条件的实证依据

段间隔按**键对类型 × 前键条件**分解（早期全量口径快照，15440 段，B4b 剔除后；量级结论在各轮口径下一致）：

| 类型 | 空前（首段） | 有前键（中段） | 差 |
|------|------------|--------------|-----|
| 跨手 | 95ms | 138ms | **+42ms** |
| 同手异指 | 105ms | 185ms | **+80ms** |
| 同键重复 | 153ms | 157ms | +4ms |
| 同指异键 | 202ms | 226ms | +24ms |
| **混合平均** | **111ms** | **164ms** | **+53ms** |

所有类型的方向一致（有前键更慢——手打完上一键不回位），但**幅度按类型不均**（跨手 +42 到同手异指 +80ms）。这正是 2 键表不可修的原因：统一比例放大修不了"同手段被低估得更多"的结构性错位（实证见 §5.3）。

模型视角（段表 S(∅,x,y) vs 平均 S(p,x,y)）：跨手 `fi` +15ms、同手异指 `wv` **+105ms**、同指同列 `az` +59ms、同键 `aa` +28ms——同手连续是前键条件最敏感的类型。

### 5.5 错误率结构实证

**签名条件的依据**：错误率随码内位置强烈爬升（首键对 ~1% → 尾对 ~3%，z=8.1；2 键码是"没爬起来就结束"的短爆发，故角点最安全），无上下文模型把位置平均掉——对 T₂ 角点条目高估 ~7ms/条目（高错误键对 ~15ms），且偏差与 P_err 成正比会扭曲 2 键简码排序；纯加法 2 特征形式被数据拒绝（角点仍高估 2×），交互项必需。部署差异：T₂ 错误成本均值 10.2→3.2ms（−7.0）、T₃ +0.3、T₄ +0.9（首段低估与尾段高估在三段和中近自消）。

**复杂度上限**（631 错误复检，容量型第三次证伪）：+键身份 one-hot 60 维 5-fold AUC 0.684、HistGBM 全特征 0.690，vs 现行（特征+签名）0.689——**瓶颈是特征信息量而非模型容量**（one-hot 后 8.6 事件/参数过参）。已识别升级路径：错误项按后键身份细化（中段上下文 P 随 n 摆动 1.4~2.5pp，Fitts(b,n) 主导）；触发条件 = 错误事件攒到 ~1200 时两批复验系数稳定性再决定。

**键对难度参考**（段间隔，早期口径 15440 段）：跨手 124ms < 同键重复 156ms < 同手异指 159ms < 同指异键 218ms。

## 6. 讨论

### 6.1 局限性

- **串行假设**：段模型假设相邻击键串行。Dhakal et al. (2018) 显示熟练打字员 40-70% 的按键存在 rollover（重叠 30-100ms）——逐段求和可能系统性高估极快打字状态。实测（key-up 字段）：重叠比例首段 56.6%、中段 10.8%、尾段 37.0%，幅值中位 35-43ms，与文献区间一致——重叠集中在首段（静止启动加速期）与尾段（提前规划收尾），中段低重叠支持"段模型对中段串行假设最可靠"
- **字母身份残余效应**：刺激以字母呈现，拼音二元组熟悉度对键对耗时存在超出几何/手指特征的小效应——偏相关 −0.08（控制 φ8 与两键基线后），高熟悉键对比零熟悉约快 7-9ms，与表条目噪声同量级、远小于当量主效应。曾考虑改用键位图显示消除字母层，评估为弊大于利（打字技能按字母组织，位置刺激退化为找键认知任务）——维持字母显示
- **时间漂移（练习效应）**：采集期速度单调提升（早期 session 中段中位 208→157ms，-24.5%），且**按键对类型不均**（同指 -60ms > 同手 -42 ≈ 跨手 -39 > 同键 -13ms）——混期当量表对当前状态的难键对成本系统性高估。处理：**稳定期口径已落地**（§5.1 边界方法自动确定稳定期，训练/测试/部署均只用稳定期数据）
- **误差重尾**：飞行时间近似 log-logistic（重尾），沉思停顿可达数秒；B4b MAD 剔除处理了异常，但纯 MAE 对重尾敏感（可考虑分位数目标）
- **单用户**：模型为个人指法特征（含小指弱势等个体差异），人群外推需 136M Keystrokes 类数据验证

### 6.2 未来工作

（精度类扩容已证无收益，§5.2；下列均为非精度目标或远期条件性条目）

- **外推口径评估**：按三元组留出评估段表外推误差——当前全局 MAE 掩盖了"2/3 条目零样本"的风险分布
- **人群先验**：136M Keystrokes 数据集（168k 人，公开免费）可作稀疏键对的先验/外部验证
- **rollover 显式建模**：key-up 字段已有——串行求和在高重叠段系统性高估，可按重叠类型修正整串口径
- **三元组交互**：Carpalx 的 k1:k2:k3 = 60:30:10 结构提示跨键对涌现惩罚，但三元组覆盖不足下三阶参数只会过拟合——数据量达标后再议
- **错误率数据积累**：~5-10 万 trial 后可升级 26 类指对嵌入/目标指难度特征（当前类别自由参数全部过拟合）

## 7. 结论与应用

本项目将击键时间成本建模从"2 键当量逐对累加"推进为"个人数据驱动的对称条件段模型"：段 S(p,a,b,n) 统一覆盖 2/3/4 键当量（同源同尺度），错误期望成本按段签名内含于"当量"定义。固定 trial 测试集上总时间 MAE 38.5ms、R² +0.643、4 码排名精度 0.809——绝对标定近完美（×k₄=1.014），且在 4 码/2 码两项上分别领先群体两键当量表 31%/51%（§5.3）。模型已贴实测噪声下界（§5.2），当前精度的剩余空间属组内生理噪声；后续增益路径为错误率模型的后键身份细化（错误事件 ~1200 时复验，§5.5）与维护性数据积累（每 ~10 session 重跑全链路）。局限性（串行假设、字母身份残余效应、单用户）见 §6.1。

应用方式（应用域 = 4 码内词内评估，§4.8）：

- **编码方案评估**：将方案的常用编码代入当量-2-4键.txt（错误成本已内含），计算平均击键总时间
- **键位优化**：调整个别键位映射后重新计算总当量，评估优化效果
- **键盘布局设计**：评估新布局的运动学效率（注意模型为 QWERTY 30 键采样训练，非 QWERTY 布局需重新采样）
