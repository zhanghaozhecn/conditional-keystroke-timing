# 击键测速 — 条件击键当量建模

**条件击键当量**（Conditional Keystroke Equivalent，简称"当量"）：从个人打字测速数据中学习**前键条件下**键位间的击键时间成本（ms，非物理距离），输出段当量母表与 2/3/4 键当量表，用于输入法编码方案评估与键位优化。

**摘要**：传统键位成本模型用 2 键当量逐对累加，假设"打完一个键手就回位"。实测表明该假设系统性低估整串耗时，且低估幅度按键对类型不均（跨手 +42ms → 同手异指 +80ms）——用其评估编码方案约 20% 的排序会被扭曲。本项目以"前键条件段"为单位建模，并已对称化（2026-08-29）：每段时间 `S(p,a,b,n)` 同时以前两键 `p,a` 与**后继键** `n` 为条件（后继键准备成本，段位效应 §6.5/§6.6），整串成本 = 段之和。在固定 trial 测试集上（稳定期内 20% 留出，无泄漏），模型总时间 MAE 40.6ms（R² +0.640；练习漂移段已按边界方法剔除、2 键角点数据参与训练，§5.1）、排名精度 Spearman 0.768，优于传统两键当量表累加（陈一凡群体表独立缩放后仍领先 29%/52%，§5.2）。

---

## 1. 背景与动机

键盘输入的成本建模是编码方案评估与键位优化的基础。传统做法（Carpalx、KLA 类工具）使用**2 键当量表** B(a,b)——键对 (a,b) 的击键时间——逐对累加估算整串耗时：

```
T'(abcd) = B(a,b) + B(b,c) + B(c,d)
```

其隐含假设：**键对间独立，打完一个键后手回到静止起始位置**。这一假设在两个层面失实：

1. **中间键对的前键从不是"空"**：打完 `r` 后手指停在 `r` 位，直接击打 `w` 的起点不是 home 位。Rumelhart & Norman (1982) 的击键时序模型早已指出相邻间隔互为条件（"间隔负相关"），且上一键准备完成后可直接启动下一键（不回位）。
2. **低估幅度按键对类型不均**：前键条件下的中段比空前键首段慢（跨手 +42ms、同手异指 +80ms），差异随类型不同——用统一比例修正不了，排序被结构性扭曲。

**条件击键当量**直接建模 `S(p,a,b,n)` = "前两键为 p,a 时击打键对 (a,b) 的时间（含后继键 n 的准备成本）"，整串成本 = 段之和：

```
T(abcd) = S(∅,a,b,c) + S(a,b,c,d) + S(b,c,d,∅)
```

2 键表是段模型在空前键（∅）+无后继（∅）下的特例切片——2/3/4 键当量同源同尺度，完全自洽。

## 3. 数据采集

### 3.1 采集协议

`python 当量采集工具.py`（tkinter GUI）：显示随机编码，录入真实击键时间戳。

**2/4 键混采（2026-08-29 起）**：每试次以 P2=0.30 概率出 **2 键码**（其余 4 键；初值 0.5，08-31 起回调 0.3 维持角点覆盖）。2 键试次服务对称段模型的 T₂ 角点 S(∅,a,b,∅) 验证（§6.6）——4 键试次的首段总带真后键，该"词首+词尾"组合只能靠 2 键试次直接测量。2 键与 4 键各用**独立的欠样本键对池**：4 键池喂段覆盖，2 键池喂 900 键对的角点覆盖；2 键行 code 长度 2、c_d/d_d=0 填充，下游按 `len(code)==4` 过滤，旧流程不受影响。

| 操作 | 行为 |
|------|------|
| 输入显示的 2/4 个字符 | 正常打字 |
| 输错（任意键） | 立即变红停止，进入随机延迟 |
| 空格 | 跳过当前组（不记录），进入随机延迟 |
| Esc | 退出 |

**采样策略（多样性加权）**：首键均匀随机，后续键按 `w(b|a) ∝ 1/(n(a,b)+1)` 加权——欠样本键对优先（符号键 `;,./` 零样本时自动补足），键对样本量趋均衡后自动回归均匀随机。每次试次结束（正确/错误/跳过统一）延迟 **300-800ms 随机**再显示下一组，打断固定节律，防止"预期性击键"把键对难度差异压缩平均。

## 4. 方法

### 4.1 问题定义

给定 4 字符编码 `abcd`，预测击键总时间 T（ms）。训练数据每行记录一个随机 4 字符串的实际击键时间戳。

### 4.2 对称条件段模型（v3 混合，2026-09-02 落地）

将序列拆成**三段**，每段独立预测，**前两键 + 后继键**共同条件（对称段模型 `S(p,a,b,n)`，采纳依据 §6.6）。神经分量 MLP 加深一层（deep2，§6.10），部署形态为 **XGB + deep2×5 固定种子混合**（无 best-of 选优，§6.10）：

```
每段 t = 双线性交互(e) + MLP(e, φ15)   S(p,a,b,n) ≈ e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b + MLP(75→64→32→1)
  前键空/无后继 = 索引 30（∅）
  φ15 = φ8(a,b) 几何 + φsuc7 后键特征 [存在, 同手(b,n), 同指(b,n), 同键(b,n), Fitts(b,n), 同手(a,n), Fitts(a,n)]
  n=∅ 时 φsuc 全 0 (存在位=0); n 仅经特征进入 (实验: 几何身份≈嵌入身份, 5 双线性无增益)

部署混合 (BlendModel): S̄ = 0.3×XGBRegressor(独热124+φ15) + 0.7×mean_{s∈{0..4}} S_deep2(s)
  无选优环节 → 无选优抽签噪声 (决策带从 ±3 缩至仅测试重洗 ~±1ms), 同数据逐位确定

整串当量统一公式 (n 键序列 k₁k₂...kₙ, k₀ = k_{n+1} = ∅):
  T_n = Σ_{i=1}^{n-1} S(k_{i-1}, k_i, k_{i+1}, k_{i+2})    首段前键=∅, 末段后键=∅

  两键  T₂(ab)   = S(∅,a,b,∅)                                        ← 1 项 (角点, 2 键试次内插)
  三键  T₃(abc)  = S(∅,a,b,c) + S(a,b,c,∅)                           ← 2 项
  四键  T₄(abcd) = S(∅,a,b,c) + S(a,b,c,d) + S(b,c,d,∅)              ← 3 项
```

版本史：v2 (2026-08-29) 增后键条件（MLP 输入 68→75，总 MAE −1.3~−1.6，两组独立 best-of-10 方向一致），段位效应（§6.5）作为 n=∅ 存在位被自然收编；v3 (2026-09-02) deep2 加深 + XGB 混合部署（两项依据 §6.10，对 v2 保留口径总 MAE 45.3→40.6）。

### 4.3 为什么前键条件（实测证据）

段间隔按**键对类型 × 前键条件**分解（15440 段，B4b 剔除后）：

| 类型 | 空前（首段） | 有前键（中段） | 差 |
|------|------------|--------------|-----|
| 跨手 | 95ms | 138ms | **+42ms** |
| 同手异指 | 105ms | 185ms | **+80ms** |
| 同键重复 | 153ms | 157ms | +4ms |
| 同指异键 | 202ms | 226ms | +24ms |
| **混合平均** | **111ms** | **164ms** | **+53ms** |

所有类型的方向一致（有前键更慢——手打完上一键不回位），但**幅度按类型不均**（跨手 +42 到同手异指 +80ms）。这正是 2 键表不可修的原因：统一比例放大修不了"同手段被低估得更多"的结构性错位（实证见 §5.2）。

模型视角（段表 S(∅,x,y) vs 平均 S(p,x,y)）：跨手 `fi` +15ms、同手异指 `wv` **+105ms**、同指同列 `az` +59ms、同键 `aa` +28ms——同手连续是前键条件最敏感的类型。

### 4.4 模型结构

输入四元组 `(p, a, b, n)` 中三键 `(p,a,b)` 经**共享嵌入**与**交互部分**两条路径汇合后加 MLP 头，后键 `n` 经 φsuc7 特征进入 MLP（sym_phi 形式）。部署为混合（XGB 分量 + 神经分量×5 平均，§4.2）。

```
输入: ids = [p, a, b, n]（31 索引, n 仅经 φ 生效）, φ15 = φ8(a,b) + φsuc7(b/a, n)
共享: e_p, e_a, e_b = E_key[ids[:, :3]]   E_key ∈ ℝ³¹ˣ²⁰（30 键 + ∅）
```

**① 神经分量（deep2，8861 参数）**——两两配对交互 + 深化 MLP：

```
S(p,a,b,n) = e_pᵀW₁e_a + e_aᵀW₂e_b + e_pᵀW₃e_b  +  MLP([e_p; e_a; e_b; φ15])
```

| 组件 | 形状 | 说明 |
|------|------|------|
| W₁/W₂/W₃ | 3 × (20×20) | 显式二阶交互：前键×首键、首键×次键、前键×次键 |
| E_key | 31×20 | 通用键位嵌入（与 W 共享同一套嵌入） |
| MLP | 75→64→32→1 (ReLU + RMSNorm) | 非线性残差（含 φsuc 后键特征）；v3 加深一层 |

**② XGB 分量（确定性）**——XGBRegressor（500 树 / lr 0.06 / depth 6 / subsample 0.8 / colsample 0.8），设计矩阵 = 独热(p,a,b,n 各 31) 124 维 + φ15 = 139 维；种子稳定 ±0.18ms；自适应部分模式匹配（叶子 = 部分键模式 + φ 区间），对零样本组合外推同样有效（§6.10 见过/未见分组）。

**③ 混合**：S̄ = 0.3×S_xgb + 0.7×mean(S_deep2, seeds 0-4)。CP 张量分解（`CPModel`）保留为历史对照（两时代皆差，§6.10）。

### 4.5 键位嵌入与交互特征

键盘为 **3 行 10 列完整 QWERTY（30 键）**：26 字母 + `; , . /`。每键独立可学习向量 `e_k = E[k]`。当量定义：**期望键对耗时，单位 ms**（模型预测原始值；2026-08-19 起废弃"除以最快速字母键对"的相对归一化方案——原归一化限定字母键对是为避免符号键污染最小值，现在不再需要）。

键位嵌入本身不含手指归属信息，显式注入 8 个文献特征：

```
φ(a,b) = [same_hand, same_finger, same_key, col_dist, row_dist, fitts,
          mirror_pair, cross_row_same_finger]

same_hand(a,b)  = 1  如果 a 和 b 在同一只手（左手=col 0-4，右手=col 5-9），否则 0
same_finger(a,b)= 1  如果 a 和 b 用同一根手指按下，否则 0
same_key(a,b)   = 1  a==b 同键重复（零幅移动需单独建模, 不适用 Fitts）
col_dist / row_dist  = |列差| / |行差|（İşeri & Ekşioğlu 2015: 列>行>手 重要性）
fitts(a,b)      = log2(1 + √(col² + (2·row)²))   Fitts 对数项, W=键宽, 行距≈2 键宽
mirror_pair(a,b)= 1  异手对称手指（Grudin 1983: 换位错误集中于镜像手指）
cross_row_same_finger(a,b) = 1  同指跨行（keygen: 同指顶↔底行最慢最易错）
```

**消融结论**（两轮）：逐特征 leave-one-out 全部持平（Δ<0.2ms，seed 方差 ±1ms）——φ 特征间互为冗余；但**整体删除损失 +1.7ms**（§6.4 无泄漏测试口径）——φ 作为整体提供嵌入补不上的几何先验，价值在稀疏三元组外推（2/3 段表条目零样本），LOO 在训练分布内做所以测不出。保留 φ8 由"文献可解释性"升级为实证支撑。

### 4.6 训练

- **目标**：批量 MSE（段级），验证集 20%，早停 patience=60，Adam lr=0.001
- **训练次数（v3 起无选优，2026-09-02）**：固定种子 0-4 训练 5 个神经分量取**预测平均**，再与确定性 XGB 混合部署（§4.2）——同数据逐位可复现。v1/v2 的 best-of-N 选优（`--trials`，验证段 MAE 选最强；选优不能用全数据——含训练集会偏向过拟合）已移除：同参数训练验证段 MAE 本身波动 ~±2ms（R² ±0.12），选优环节引入的抽签噪声（±2ms，§5.1）随之从管线消失
- **可复现性（2026-08-18 起）**：`击键模型.py` 导入时固定运行环境（`torch.set_num_threads(1)` + `torch.manual_seed(0)`）。此前新进程的 torch 默认 RNG 为熵播种、模型构造（嵌入/线性层初始化）依赖它，而 `train(seed)` 只重播轨迹不重播构造——这是"同命令重跑结果漂移"的主因（±1.4ms 报告波动的很大一部分）。现在同代码+同数据**跨进程逐位可复现**（各变体 best-of-N 的初始化沿确定性流推进，仍互不相同）；单线程对此规模模型还快 ~20%。历史表数字与新固定值差异均在原噪声带内
- **验证集泄漏（2026-08-14 实测）**：同一 trial 的三段共享个人速度因子（trial ICC 0.308，段间相关 corr(t₁,t₂)=0.690、corr(t₂,t₃)=0.844），段级随机划分使验证集与训练集共享 trial——验证段 MAE 系统性偏乐观约 9ms（33.5 vs 42.6，21%）。历史 best-of-N 选优曾沿用此段级验证；**模型对比与报告口径必须用 trial 级留出**（固定 20% trial 测试集，测试 trial 的段不进训练/验证），见 §5.1 口径矩阵
- **异常剔除（B4b 两阶段残差，键对分桶）**（2026-08-12 落地，替代单阶段 MAD；开发链实验脚本已删除，结论存档本节与 `击键模型.py` docstring）：
  1. 段位置分桶 MAD k=3 剔除 → 训练 M0（5 seeds 验证集选优，干净模型提供"期望行为"）
  2. M0 推全数据 → 带符号残差 `y−ŷ`（正 = 比预期慢）
  3. 残差按**键对 (a,b) 分桶**、**单侧上围栏**（r ≥ med + 3·1.4826·MAD）剔除——键对系统性偏差中心化后只删"比该键对合理预期慢"的段（真注意力中断）。**方向语义（2026-08-20）**：异常只可能偏大——注意力中断只拖慢不拖快，打得比预期快是 rollover/预备连击（真实打字行为）不删；原 |残差| 双侧判据曾把 16%（全量）/35%（测试集）的删除错放快侧，单侧化后修正
  - 依据：全局残差法会把"比模型预测慢"的真实慢段当异常删——模型学不会的难键对（pq 跨手双小指）17 段删 7 段，当量 162→95ms 失真（用模型偏见定义正常，循环论证）；键对分桶修复后当量恢复。固定测试集终局对比各方案 44-47ms 在噪声内——剔除收益在**当量稳健性**（防中断段拉偏键对当量）而非预测精度。剔除率 ~4.8% 在文献范围（van Selst & Jolicoeur 1994 n 依赖法调研，5-10% 常见）
  - 验证：合成注入 +300ms 真异常 100% 检出（recall），误删率≈基线剔除率；剔除集 5 M0 seed Jaccard 0.977（结构性稳定）
- 段样本：每 trial 3 段（t₁: 空→ab, t₂: a→bc, t₃: b→cd），共享 MLP 头，段间互相增强

### 4.7 设计边界

- ❌ **字母 N-gram 频率**：不引入自然语言熟悉度偏差，纯随机采样
- ❌ **连组模式**：每组独立开始（模拟分词间自然停顿），不建模组间转移
- ❌ **节奏/节拍器**：随机延迟打断节律，按"打对条件下尽可能快"测试
- ❌ **变长编码**：仅测 4 字符编码（2/3 键当量为段表切片组合）

## 5. 结果

### 5.1 模型精度（B4b 剔除，固定 trial 测试集）

**统一口径（2026-08-30 起）：稳定期内固定 trial 测试集**（用户决策；此前 08-19 起为全量混合划分——练习漂移段使模型对当前状态系统性偏慢 ~12ms，§6.7，两口径数字不可比）。`stable_pools`（击键模型.py）边界方法：每 session 正确 4 键 trial 总时中位 → 3-session 滚动中位平滑 → R = 末 5 个平滑值中位 → 自末向前最早连续满足 平滑值 ≤ R×1.10 的 session 起（确定性无随机，抗单 session 异常）；稳定期内 seed 2024、20% trial 留出，训练/评估只作用于训练侧（训练集 B4b + 固定混合训练），测试集独立 B4b（内部自训 M0，与训练无信息交换）。`python 击键模型.py` 直接输出（确定性流，重跑必得同值）。**部署模型同用稳定期全量**（当量表 = 当前状态语义）。**例外：错误率模型（分析-错误率规律.py）仍用全部数据**（错误率按用户决策不随练习过滤）。**全数据（含训练集）口径已废弃**（训练集评估偏差实测 +14.3ms，系统性乐观）。

1. **用途匹配**：当量表服务于编码方案评估与键位优化（相对排序）。被剔段是注意力中断，与键对难度无关、对候选编码近似同分布的加性噪声——计入指标只稀释难度信号（拉低 R²），不提供方案设计信息

### 5.3 修正段当量与 2-4 键当量（2026-08-31 定稿：错误成本内含）

一次按键错误的时间成本 = 退格 + 注意力重定位 + 重输 ≈ **固定 500ms**（数据推导 ~455ms：错键段 160-221 + 退格 180 + 重打首键 102），与键对运动难度解耦。错误成本按段自身键对计入，构成本项目标准产物链（`组装当量表.py`）：

```
修正段当量 C(p,a,b,n) = 段当量 S(p,a,b,n) + 500ms × P_err(a,b)   → 当量-修正段表.npz
2-4 键当量 = 修正段求和:                                            → 当量-2-4键.txt
  T₂(ab)   = C(∅,a,b,∅)                    T₃(abc)  = C(∅,a,b,c) + C(a,b,c,∅)
  T₄(abcd) = C(∅,a,b,c) + C(a,b,c,d) + C(b,c,d,∅)
```

即**本项目"当量"的完整定义包含错误期望成本**（2026-08-31 前的"期望当量"概念并入标准定义；原始段表与错误率表作为两个源表一并保留）。

**键对错误率模型**（`分析-错误率规律.py`，9 特征逻辑回归，30666 键对事件 / 623 错误，5-fold AUC 0.642±0.023；2026-09-02 快照）：

```
P_err(a,b) = σ(−4.328 + 0.504·同手 − 2.075·同指 + 2.451·同指同列
             + 0.258·无名-中指 + 0.475·小指-无名 + 2.414·同指双列
             + 0.151·b左小指 − 0.312·b顶行 + 0.453·b底行)
```

特征全为键位可计算量（`同手/同指` 手位关系、4 个坏指对、`b左小指` 及目标键行）。原始统计级错误率噪声大（每键对平均 ~34 事件），模型输出受特征结构约束更稳。系数是正确率模型取反——`同指` 负系数因含同键重复（0.3% 低错）拉低，坏子类由坏指对特征单独暴露。

**键对难度参考**（段间隔，15440 段）：跨手 124ms < 同键重复 156ms < 同手异指 159ms < 同指异键 218ms。

## 6. 讨论

### 6.1 局限性

- **串行假设**：段模型假设相邻击键串行。Dhakal et al. (2018) 显示熟练打字员 40-70% 的按键存在 rollover（重叠），重叠 30-100ms——逐段求和可能系统性高估极快打字状态。实测（key-up 字段，2026-08-14）：重叠比例首段 56.6%、中段 10.8%、尾段 37.0%，幅值中位 35-43ms，与文献区间一致——重叠集中在首段（静止启动加速期）与尾段（提前规划收尾），中段低重叠支持"段模型对中段串行假设最可靠"
- **字母身份残余效应（2026-08-20 实测）**：刺激以字母呈现，拼音二元组熟悉度对键对耗时存在超出几何/手指特征的小效应——偏相关 −0.08（p=0.03，控制 φ8 与两键基线后），高熟悉键对比零熟悉约快 7-9ms，与表条目噪声（标准误 ~11ms）同量级、远小于当量主效应（同手异指 +80ms）。单侧剔除已过滤"难读串中途回看"的慢侧成分，残余为熟悉组块的加速（快侧，按语义保留）。曾考虑改用键位图显示消除字母层，评估为弊大于利（打字技能按字母组织，位置刺激退化为找键认知任务）——维持字母显示，熟悉度如需处理在应用层校正
- **时间漂移（练习效应，2026-08-14 实测）**：采集期（07-24→08-11）速度单调提升——session 中段中位 208→157ms（-24.5%，Spearman ρ=-0.79），错误率无变化（真技能提升）；08-08 后进入平台期（145-167ms）。漂移**按键对类型不均**（同指 -60ms > 同手 -42 ≈ 跨手 -39 > 同键 -13ms），相对难度结构也在漂移，混期当量表对当前状态的难键对成本系统性高估。处理：**已落地稳定期口径（2026-08-30，§6.7/§5.1）**——边界方法自动确定稳定期，训练/测试/部署均只用稳定期数据，混期高估已消除（时间归一化曾测不落地——过渡收益在噪声内，实验脚本已删、结论存档）
- **误差重尾**：飞行时间近似 log-logistic（重尾），沉思停顿可达数秒；MAD 剔除处理了异常，但纯 MAE 对重尾敏感（可考虑分位数目标）
- **单用户**：模型为个人指法特征（含小指弱势等个体差异），人群外推需 136M Keystrokes 类数据验证

### 6.2 文献特征消融（2026-08-11）

错误率模型侧：镜像手指/跨行同指/相邻手指/方向不对称 4 个文献特征**无增益**（13 特征 AUC 0.619 ≈ 9 特征 0.620）——与现有坏指对高度共线。分层确认：镜像手指在本数据是**保护项**（2.87% < 非镜像 3.86%——Grudin 的换位错误占比 ≠ 键对风险）；b 离拇指侧更易错（5.16% vs 3.87%，Lachnit 方向不对称确认）。双向计数（错键事件并入）AUC 降至 0.600 但错误事件翻倍、校准更稳（`--dual` 开关保留）。

### 6.3 未来工作

### 6.5 段位效应（2026-08-26，脚本已删、结论存档本节）

中段中位 ~150ms 明显慢于尾段 ~128ms，但两者输入结构相同（前键+键对、同分布随机采样）——差异只能来自**段在串中的位置**。实证：

- **效应量化（键对级配对，872 对两侧 n≥2）**：同一键对在中位比尾位慢 **+19.8ms**（中位更慢占 74% 对）；**随类型交互**——跨手 +25.8、同手 +22.9、同指 +5.4、同键 **−7.6**（反向）。机理：尾段是"甩出"的末键（无后继键需准备，rollover 重叠率 37.5% vs 中段 11%；含 §3.3 历史释时偏差，无重复字母子集约再 +3~5pp，方向不变），中段需同时准备下一键
- **部署模型残差的段位偏差**：统一模型对中段系统性低估（+7.0ms）、尾段系统性高估（−13.5ms）——平均化使两 slot 各错 ~10ms
- **三方案对比**（保留口径，best-of-10）：

| 变体 | 段MAE | 总MAE | R² | 段位分解（首/中/尾） |
|------|-------|-------|-----|---------------------|
| baseline（统一，现行） | 36.7 | **67.9** | **+0.338** | 31.0 / 39.6 / 39.3 |
| 统一+段位 one-hot | 35.4 | 68.6 | +0.313 | 30.2 / 38.5 / 37.5 |
| 分段独立模型 | **35.2** | 68.4 | +0.313 | 30.4 / 38.0 / 37.2 |

结论：
1. **段级预测段位感知更好**（段 MAE −1.3~1.5ms，三个段位均改善）；**整串预测无收益**（baseline 反而最优，差异在噪声带内）——每个四码恰好含一个中段+一个尾段，位置效应的主成分在三段求和中抵消，统一模型的"平均化"等效于 slot 偏移互消
2. **完全分段独立无额外好处**：各 1/3 数据的稀释抵消位置保真（与 φ8 的稀疏外推教训一致）；若需段位感知，"+3 输入维 one-hot"是即插即用选项（共享全部键位嵌入）
3. **应用域限定（2026-08-27）——当量的优化与使用仅限 4 码内**：当量的应用对象是 4 码二字词（2/3 码单字简码同表覆盖），打字时词与词之间自然存在分词间隔，**连续输入（跨词无间隔序列）不在建模与应用范围内**。该限定下，此前"尾段折扣可能是装置伪影"的警示失效：孤立 4 键试次的范式（词前有间隔、词内 4 键连击、词后是间隔）与真实二字词输入结构一致，尾段"甩出"就是词末键的真实成本结构，统一模型的中/尾 slot 偏差在 T₄ 求和中精确互消。仅当未来扩展到跨词连续序列评估时，才需要改用"位置=中段"的表语义

| fpair16 | 31 | −0.12（6/10） | +0.1 | +0.00 |
| fpair64 | 79 | −0.19（8/10） | +0.2 | **+0.27（变差）** |

结论：**三变体全部与 base 等价**（Δ均在种子噪声内），fpair64 反而伤角点（64 维稀释薄角点池）。机理解释：键嵌入 + 双线性 e_aᵀW₂e_b 本身就是学出来的**键对**（因而也是指对）类别表示，且 900 键对比 64 指对类别更细——手工指对独热携带的信息是嵌入的严格子集，只能提供归纳偏置而非新信息，实测该偏置无增益。同指侧移无独立效应（同指=1 + Fitts 已覆盖该几何）。去列距不伤精度的原因是 Fitts 仍含列分量（列信息未真正移除）。**特征工程两轮共 11 变体全部关闭，φ8 文献特征集维持原样**。

脚本保留为可复跑工具（CLI：`python 实验-特征消融2.py 变体表 种子表`；v3 换 deep2 M0 后旧掩码缓存已删，重跑自动重建），不在发布清单。

### 6.10 架构重开——稳定期数据全面重审（2026-09-01，`实验-架构对比.py`）

**动机**：现行 sym_phi 的结构结论多为 v1 全量混合数据口径（08-18 复跑已见结构排序不复现）；数据现为稳定期（练习漂移已剔）+ 角点参与训练 + 后键条件，架构排序可能不同。约束：S(p,a,b,n) 条件段表示与 φ15 输入不变，只变函数类。协议与 §6.9 一致（共用 B4b+MAD 掩码、配对种子 mean±std、角点单次 MAE 主指标），神经变体 5 种子（候选另跑独立批 10-14）。

**关键发现**：

1. **树模型翻案（v1 时代 R² 全负 → 现四项指标全优）**。机理：稳定期消灭分布漂移（树不能外推但不再需要外推时间轴）；独热+φ 设计矩阵下树做的是自适应部分模式匹配（叶子=部分键模式+φ 区间）。**优势不是记忆**：test4 三元组 44% 见过/56% 未见过分组下，GBM 对 base 的段优势均匀（见过 −1.63 / 未见 −1.60），未见惩罚两模型相同（+6.1ms，数据属性）。GBM 十个 random_state 逐位相同（零方差）；超参扫（迭代/叶子/损失 9 配置）默认最优——加大迭代过拟合（2000→47.0）。44.1 为盲选默认配置数字，无测试集调参。
2. **MLP 深度价值显形**：单层→双层 −2.2~−2.5（10/10 配对），三层饱和。v1"de20/dh64 单层最优"结论为混合数据口径，稳定期失效；单层 base 的容量恰是不够的。双线性三项价值也不复现（mlp_only/no_w3 ≈ base）——现行 base 的两个"已收敛"结论都是数据分布混合造成的伪收敛。
3. **种子集成收益 −2.2**（deep2 单模 45.2 → 5 种子预测平均 43.0）：神经预测方差被平均掉，非选优稳定化（此前否决的"集成"是 best-of 选优稳定化，与此不同——这是部署侧预测平均，全部种子入集无挑选）。
4. **段 MAE 26.3-26.6 已触及 §6.8 实测噪声底 26.6**；总 42.6 低于独立段假设的底 ~46（段误差在 trial 内负相关，或 σ_seg 估计含后继效应方差偏高——底是软的）。角点 15.7-15.8 对底 13.3。

**候选采纳方案（待用户确认）**：deep2ens5（单一 torch 家族，管线改动最小：MLP 加一层 × 5 种子预测平均入段表）vs blend（再 −0.4ms 但引入 sklearn 第二家族）。GBM 单模 44.1 逊于 deep2ens 43.0，仅作 blend 分量。

**【2026-09-02 落地】用户确认采纳混合（xgb 0.3 + deep2×5 固定种子平均）**：`击键模型.py` v3——KeystrokeModel 升级 deep2 结构（8861 参数）、新增 `BlendModel`/`train_xgb`/`design_matrix`、main() 评估与部署均改混合（无 best-of 选优，`--trials`/`--model` 旗标移除）、模型双文件导出（keystroke_model.pt + 击键模型-xgb.json，`BlendModel.load()` 回路验证模型 API 与段表逐位一致）；`对比-条件vs陈表.py` 同步混合；B4b 剔除 M0 随之变为 deep2（保留 9587/9930，旧掩码缓存已删）；sync 清单加 xgb.json。**落地指标（保留口径）：段 25.7 / 总 40.6 / R² +0.640 / 角点 15.3 偏差 +0.0**（v2 为 28.5/45.3/+0.565/17.8+1.7）。附带收益：选优抽签噪声从管线中消失，跨快照波动仅剩测试重洗 ~±1ms。

**第三轮：表格回归全家族补扫（同日追加，`实验-架构对比2.py`，检索后补齐未试家族）**。文献依据：表格数据 2022-2025 基准共识 GBDT 仍强、FT-Transformer/ResNet 为深度侧代表、神经侧最有效技巧为高斯秩目标变换（Grinsztajn et al. 2022 及后续）；击键动力学文献（生物识别导向）无新回归家族。

第三轮结论：①文献共识与本数据一致——GBDT（xgb 43.7 > HistGBM 44.1 > rf 46.9 > et）是最强单模家族，深度表格代表（FTT/ResMLP）不占优；②神经侧所有文献技巧（残差/注意力/token 化/全局交互/目标变换）无一超过 deep2，深度收益全部来自"加深一层 + 种子平均"这两个朴素操作；③全局最优 = **xgb×deep2ens5 ≈ 42.2-42.5 / R²+0.60 / 段 26.2（噪声底）/ 角点 15.5**，比 deep2ens5 单独再 −0.5ms（低于决策带，可选）。采纳方案不变：deep2ens5 为主选，xgb 混合为可选增强。

## 7. 应用

- **应用域**：当量仅用于 4 码内的词内评估（主要是 4 码二字词，2/3 码简码同表覆盖）；词间分词间隔自然存在，跨词连续序列不在建模范围（§6.5 结论 3）
- **编码方案评估**：将方案的常用编码代入当量-2-4键.txt（错误成本已内含），计算平均击键总时间
- **键位优化**：调整个别键位映射后重新计算总当量，评估优化效果
- **键盘布局设计**：评估新布局的运动学效率（注意模型为 QWERTY 30 键采样训练，非 QWERTY 布局需重新采样）

## 8. 复现

### 命令链

```bash
python 当量采集工具.py                   # 1. 采集（可选：已有数据可直接训练）
python 击键模型.py --full               # 2. 稳定期测试集评估 + 部署模型训练 + 导出段表 npz 与模型双文件
python 分析-错误率规律.py               # 3. 错误率模型（全量数据）→ 当量-键对错误率.txt
python 组装当量表.py                    # 4. 修正段表.npz（段+500×P_err）+ 2-4键.txt（修正段求和）
```

### 输出文件（标准产物四件 + 模型双文件）

| 文件 | 内容 |
|------|------|
| 当量-段表.npz | 原始段母表 S[p,a,b,n] (31,30,30,31) ms + 元数据（npz，程序消费） |
| 当量-键对错误率.txt | 900 键对 P_err（9 特征逻辑回归，全量数据训练） |
| 当量-修正段表.npz | 修正段当量 C = S + 500ms×P_err(a,b)，p/n 维广播（§5.3） |
| 当量-2-4键.txt | 837,900 条 2/3/4 键总当量 = 修正段求和（ms，错误成本内含） |
